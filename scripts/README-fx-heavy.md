# مدل‌های سنگین ارز — اجرا روی PC خودت

مدل‌های سبک (PPP/پولی/حساسیت/پیش‌بینی نقطه‌ای) در خودِ سایت زنده اجرا می‌شوند
(`lib/fx/engine.ts`). این پوشه، «نیمهٔ سنگین» را می‌سازد: آزمون آماری حباب
(**PSY/GSADF**)، نوسان (**GARCH**)، بازهٔ احتمالاتی (**مونت‌کارلو**) و **هم‌جمعی**.
چون کتابخانهٔ معادلِ statsmodels/arch در TypeScript نیست، این‌ها گاه‌به‌گاه در
پایتون روی PC تو حساب می‌شوند و نتیجه در جدول append-only `fx_heavy_analytics`
می‌نشیند؛ صفحهٔ `/admin/fx` تبِ «آزمون‌های آماری» فقط همان را نمایش می‌دهد.

> PC فقط **لحظهٔ اجرا** روشن است، نه دائمی. هیچ سروری اضافه نمی‌شود.

## نصب (یک‌بار)
```bash
pip install -r scripts/requirements-fx-heavy.txt
```
یک فایل `.env` کنارِ ریشهٔ پروژه (کامیت نشود) با دو کلید:
```
SUPABASE_URL=https://<project>.supabase.co
SUPABASE_SERVICE_ROLE_KEY=<service-role-key>   # فقط سمت تو؛ هرگز در ریپو
```

## اجرای ماهانه (وقتی دادهٔ ماه جدید آمد)
```bash
python scripts/fx-precompute-heavy.py
```
- ورودی = دقیقاً همان seedهای سایت (`lib/fx/data/*.json` + override احتمالی در
  Supabase)، پس محاسبات با سایت **واگرا نمی‌شود**. خودآزمونِ PPP قبل از هر اجرا
  با مقادیر طلاییِ `engine.ts` چک می‌شود؛ اگر نخورد، اسکریپت **متوقف** می‌شود
  (به‌جای تولیدِ عددِ مشکوک).
- یک ردیفِ **جدید** درج می‌شود (نسخه‌دار، append-only)؛ ردیف قبلی پاک نمی‌شود.

### تست بدون درج
```bash
python scripts/fx-precompute-heavy.py --emit-json out.json
```

## فعال‌کردنِ GARCH و PSYِ باتوان (اختیاری ولی مهم)
با دادهٔ **سالانه**، فقط مونت‌کارلو کامل است؛ PSY «کم‌توان/نمایه‌ای» و **GARCH خاموش**
(چون به سریِ پرتواترِ دلار نیاز دارد). سریِ ماهانه/روزانهٔ دلار را بده تا هر دو فعال شوند:
```bash
python scripts/fx-precompute-heavy.py --usd-csv dollar_monthly.csv
```
CSV با دو ستون: `date,usd_toman` (هر ردیف یک ماه/روز). با ≥۶۰ مشاهده، GARCH روشن
و نوسانِ مونت‌کارلو از دادهٔ واقعی **برآورد** می‌شود (به‌جای فرض).

## گزینه‌ها
| فلگ | کار |
|---|---|
| `--horizon N` | افق مونت‌کارلو (ماه، پیش‌فرض ۱۲) |
| `--mc-annual-vol 0.25` | نوسانِ سالانهٔ فرضی وقتی سری دلار نیست |
| `--mc-seed 20260722` | seed پین‌شده (بازتولیدپذیری) — در جدول ثبت می‌شود |
| `--start-rate / --start-shamsi` | نرخِ شروعِ دستی اگر خواندنِ زندهٔ fx_rates ممکن نبود |
| `--psy-reps 499` | تعداد شبیه‌سازیِ مقادیر بحرانی PSY |

## قواعد صداقت (چرا این‌طور طراحی شده)
- **دادهٔ ناموجود = `null` با ذکرِ دلیل**، هرگز عددِ ساختگی. (GARCH با دادهٔ سالانه = null.)
- بازهٔ مونت‌کارلو **مشروط بر فروض** است (تورم/نوسان)، نه پیش‌بینیِ قطعی؛ فروض در جدول ثبت می‌شود.
- خروجی **توصیفی** است، نه توصیه؛ واژهٔ سیگنال/خرید/فروش در UI نمی‌آید.
- هر اجرا نسخهٔ کتابخانه‌ها + تاریخِ محاسبه + seed را ثبت می‌کند (ممیزی‌پذیری).
