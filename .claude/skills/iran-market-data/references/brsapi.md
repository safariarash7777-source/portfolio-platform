# کاتالوگ BrsApi — تنها منبع دادهٔ قراردادی «قطب‌نمای بازار»

> منبع این کاتالوگ: مستندات رسمی که آرش از پنل brsapi.ir تحویل داده (تیر ۱۴۰۵) + کد رلهٔ در حال اجرا.
> **endpoint یا پارامتری که اینجا نیست را حدس نزن** — URL اشتباه = بن IP دست‌کم ۲ ساعته.
> کلید API هرگز در چت/کامیت/لاگ نیاید؛ فقط env رله.

## سهمیه‌ها
- کلید اصلی (پلن AIO): **۱۰٬۰۰۰ درخواست/روز**. کلید کامودیتی جهانی جدا و رایگان: **۱٬۵۰۰/روز**.
- هر مصرف‌کننده باید سقف روزانهٔ صریح + شمارنده در `/debug` رله داشته باشد. جمع برنامه‌ریزی‌شده ≤ ~۵٬۵۰۰ بماند (حاشیه برای بک‌فیل‌ها).
- User-Agent مرورگر در همهٔ درخواست‌ها الزامی است (`HDRS` در `relay/server.mjs`).

## زخم‌های تجربه‌شده (تکرار نشود)
1. **PostgREST Max Rows (~۱۰۰۰):** هر SELECT بزرگ بی‌صدا بریده می‌شود — علت باگ ۵۸هزار ردیف تکراری symbol_history. راه‌حل ثابت: unique index + `on_conflict` + `Prefer: resolution=ignore-duplicates`؛ خواننده‌ها dedupe «جدیدترین id» دارند.
2. **زیرنمادها در فیدها:** AllSymbols و Candlestick زیرنمادهای بلوکی را هم می‌دهند؛ بدون فیلتر Z1، سهمیه و دیتابیس آلوده می‌شود (سابقه: ۵۵۹ زیرنماد، ~۳۸هزار ردیف).
3. **NAV برای نماد فاقد NAV:** اخطار رسمی BrsApi. فهرست سیاه پایدار الزامی.
4. **واحدها:** فیدهای قیمت ریال‌اند؛ ن-۱۰/ن-۳۰ «میلیون ریال». تبدیل فقط یک‌بار در مرز ingest با کامنت.
5. سایت اصلی از IP خارج از ایران در دسترس نیست/۴۰۳ می‌دهد؛ مستندات جدید فقط از پنل آرش می‌آید.
