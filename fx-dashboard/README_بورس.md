# راهنمای آپدیت داده بورس

تب «📊 بورس» داشبورد از فایل **`تحلیل_کامل_بورس_جاری.xlsx`** تغذیه می‌شود.
این فایل به‌صورت خودکار از فایل خامِ Screener Plus ساخته می‌شود — نیازی به ویرایش دستی نیست.

## چطور داده را آپدیت کنم؟

۱. فایل خامِ جدیدِ screener را در پوشه‌ای در دسترس بگذار (مثلاً Downloads).
   نام فایل بهتر است شامل تاریخ شمسی باشد، مثل `screener-plus-1405-06-31.xlsx`.

۲. این دستور را اجرا کن:

```powershell
cd "C:\Users\arsa\Desktop\داشبورد"
python build_stock_analysis.py "C:\Users\arsa\Downloads\screener-plus-1405-06-31.xlsx"
```

> اگر آرگومان ندهی، اسکریپت از مسیرِ پیش‌فرضِ `RAW_DEFAULT` (بالای فایل اسکریپت) استفاده می‌کند.

۳. تمام. اسکریپت دو فایل می‌سازد:
   - `تحلیل_کامل_بورس_<تاریخ>.xlsx` — نسخهٔ آرشیویِ تاریخ‌دار
   - `تحلیل_کامل_بورس_جاری.xlsx` — کپیِ ثابتی که **داشبورد همیشه از آن می‌خواند**

۴. داشبورد را یک‌بار ری‌استارت کن (چون ماژول‌ها کش می‌شوند):

```powershell
Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
  Where-Object { $_.CommandLine -match 'streamlit' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
streamlit run app.py
```

تب بورس خودکار داده‌ی تازه را نشان می‌دهد.

## خروجی اسکریپت چیست؟

یک فایل اکسل با ۵ شیت:

| شیت | محتوا |
|---|---|
| `راهنما` | تاریخ داده، روش امتیاز مرکب، میانهٔ بازار، هشدارهای تحلیلی |
| `صنایع` | میانهٔ شاخص‌ها برای هر صنعت + امتیاز مرکب + رتبه + وزن بازار + دلاری٪ |
| `سهام` | همهٔ سهام با شاخص‌های ارزش‌گذاری/رشد/کیفیت/بازده |
| `سکتورها` | میانهٔ شاخص‌های ۱۲ سکتور اصلی |
| `نگاشت سناریو` | صنایع برندهٔ تشدید (دلاری) در برابر برندهٔ گشایش (ریالی) |

## روش‌شناسی (خلاصه)

- **هدر** فایل خام در ردیف ۸ است (`header=7`)؛ ردیف‌های بدون `Symbol` حذف می‌شوند.
- **تبدیل امن عددی:** حذف کامای هزارگان، تبدیل `-` به NaN، `to_numeric(errors='coerce')`، حذف بی‌نهایت.
- **پاکسازی P/E:** مقادیر ≤۰ یا >۱۰۰ حذف می‌شوند (زیان‌ده/نویز).
- **درصدها** ×۱۰۰ و **ارزش بازار** ÷۱e۱۳ (به همت).
- **امتیاز مرکب** = میانگین z-score چهار بُعد با وزن مساوی روی صنایعِ دارای ≥۴ شرکت:
  ارزش (−z نمرهٔ P/E) · رشد (z رشد سود، محدود به ±۲) · کیفیت (z ROE) · حاشیه (z حاشیهٔ خالص).
  انحراف معیار نمونه‌ای (`ddof=1`) استفاده می‌شود.
- **دلاری٪** = نسبت شرکت‌های با خالص ارزیِ مثبت، تنها میان شرکت‌هایی که دادهٔ خالص ارزی دارند.

## اعداد مرجع (داده خرداد ۱۴۰۵، برای صحت‌سنجی)

- صنایع: ۶۱ ردیف · سهام: ۹۰۶ ردیف · سکتورها: ۱۲
- رتبهٔ ۱: «سیمان، اهک و گچ» (امتیاز ۱.۲۸) · خودرو نزدیک انتها (رتبهٔ ۴۳)
- میانهٔ بازار P/E ≈ ۷.۴
