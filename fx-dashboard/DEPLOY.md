# دیپلویِ داشبورد روی لیارا + اتصال به پنلِ ادمین

داشبورد داخلِ `iframe` در مسیرِ `/admin/fx` سایت نشان داده می‌شود، ولی خودش روی
یک اپِ جدا روی **لیارا (داخلِ ایران)** اجرا می‌شود.

## چرا لیارا و نه Vercel؟

| دلیل | توضیح |
|---|---|
| Streamlit سرورِ دائمی است | با WebSocket کار می‌کند؛ Vercel serverless است و اجرایش نمی‌کند. |
| داده باید از داخلِ ایران بیاید | داشبورد مستقیم از tgju می‌خواند و tgju به درخواستِ خارج از ایران **۴۰۳** می‌دهد — همان دلیلی که `relay/` در ریپوی سایت روی لیاراست. میزبانیِ خارجی یعنی نرخِ زنده، تبِ حباب و بورس مرده. |

## معماریِ دسترسی

```
مرورگرِ ادمین
   ├─▶ سایت (Vercel) /admin/fx
   │     ├─ layout.tsx: نقشِ admin از profiles.role چک می‌شود  (از قبل بود)
   │     └─ سمتِ سرور یک توکنِ HMAC با عمرِ ۱۰ دقیقه می‌سازد (lib/fxToken.ts)
   │           └─ <iframe src="https://<app>.liara.run/?embed=true&t=<token>">
   └─▶ داشبورد (لیارا، داخلِ ایران)
         └─ auth_gate.py امضا و انقضا را چک می‌کند → session_state
```

**نکتهٔ مهم:** خودِ `iframe` هیچ محافظتی نیست. `middleware.ts` سایت فقط مسیرهای
دامنهٔ خودش را گیت می‌کند، پس بدونِ این دروازه هرکسی با داشتنِ آدرسِ لیارا
داشبورد را باز می‌کرد. کلیدِ مشترک هیچ‌وقت به مرورگر نمی‌رود؛ فقط توکنِ مشتق‌شده.

توکن فقط برای **ورود** است. بعد از یک‌بار تأیید، نشست در `session_state` می‌ماند
و انقضای توکن کاربرِ در حالِ کار را بیرون نمی‌اندازد.

---

## قدم ۱ — کلیدِ مشترک بسازید

```bash
openssl rand -base64 48
```

همین یک مقدار در **هر دو جا** ست می‌شود. هرگز کامیت نشود و هرگز `NEXT_PUBLIC_` نشود.

## قدم ۲ — اپِ لیارا

1. در پنلِ لیارا یک برنامهٔ جدید با پلتفرمِ **Docker** بسازید (مثلاً `arash-fx`).
2. متغیرهای محیطی را ست کنید:

   | متغیر | مقدار | اجباری |
   |---|---|---|
   | `FX_EMBED_SECRET` | خروجیِ قدم ۱ | ✅ بدونش داشبورد **بسته** می‌ماند |
   | `GEMINI_API_KEY` | کلیدِ Gemini | فقط برای تبِ دستیار |
   | `FX_TOKEN_TTL` | `600` | اختیاری |

   `FX_REQUIRE_AUTH=1` داخلِ `Dockerfile` ست شده — دست نزنید. طراحی
   **fail-closed** است: اگر `FX_EMBED_SECRET` را یادتان برود، داشبورد بسته
   می‌ماند، نه اینکه عمومی شود.

3. از همین پوشه دیپلوی کنید:

   ```bash
   npm i -g @liara/cli      # یک‌بار
   liara login
   liara deploy --app arash-fx --platform docker
   ```

   لیارا خودش ایمیج را می‌سازد؛ Docker روی سیستمِ شما لازم نیست.

4. تست: `https://arash-fx.liara.run` را باز کنید — باید پیغامِ **«🔒 دسترسی مجاز
   نیست»** بدهد. اگر داشبورد باز شد یعنی `FX_EMBED_SECRET` ست نشده.

## قدم ۳ — سمتِ سایت (Vercel)

در **Vercel → Settings → Environment Variables**:

| متغیر | مقدار |
|---|---|
| `FX_DASHBOARD_URL` | `https://arash-fx.liara.run` |
| `FX_EMBED_SECRET` | **دقیقاً** همان مقدارِ قدم ۱ |

سپس **Redeploy** بزنید.

> ⚠️ `FX_DASHBOARD_URL` فقط آدرس نیست — `next.config.js` از آن `frame-src` در
> CSP را می‌سازد. اگر Redeploy نزنید، مرورگر قاب را بلاک می‌کند و صفحهٔ
> `/admin/fx` سفید می‌ماند.

## قدم ۴ — بررسی

وارد `/admin/fx` شوید (با حسابی که `profiles.role = 'admin'` دارد). باید داشبورد
داخلِ صفحه بیاید.

## عیب‌یابی

| نشانه | علت | درمان |
|---|---|---|
| صفحهٔ `/admin/fx` می‌گوید «داشبورد هنوز وصل نشده» | `FX_DASHBOARD_URL` یا `FX_EMBED_SECRET` روی Vercel نیست | ست کنید و Redeploy |
| قابْ سفید و کنسول می‌گوید `Refused to frame … CSP` | بعد از ست‌کردنِ `FX_DASHBOARD_URL` ری‌دیپلوی نشده | Redeploy |
| داخلِ قاب «🔒 دسترسی مجاز نیست» | کلیدِ دو طرف یکی نیست، یا ساعتِ سرورها بیش از ۱۰ دقیقه اختلاف دارد | مقدارها را مقایسه کنید |
| داخلِ قاب «پیکربندی ناقص است» | `FX_EMBED_SECRET` روی لیارا ست نشده | روی لیارا ست کنید |
| نرخِ زنده نمی‌آید / تبِ بورس خالی | اپ خارج از ایران اجرا می‌شود یا IP بلاک است | حتماً روی هاستِ ایرانی |
| قاب مدام «Connecting…» می‌شود | XSRF یا CORS دستکاری شده | مقادیرِ `STREAMLIT_SERVER_ENABLE_*` در `Dockerfile` باید `false` بمانند |

## داده‌ها

فایل‌های اکسل داخلِ ایمیج می‌روند و **سریِ تاریخی ثابت است** — با گذشتِ زمان
کهنه می‌شود. برای به‌روزرسانی، فایلِ جدید را جایگزین کنید و دوباره دیپلوی.
`.streamlit/secrets.toml` در `.dockerignore` است و داخلِ ایمیج نمی‌رود؛ کلیدِ
Gemini فقط از متغیرِ محیطی خوانده می‌شود (`gemini.py` خودش هر دو را پشتیبانی
می‌کند).

کشِ مقادیرِ بحرانیِ PSY روی `/tmp/psy_cache` می‌نشیند که با هر ری‌استارت پاک
می‌شود — مهم نیست، بازتولیدش چند ثانیه است.
