> اگر فقط ۵ دقیقه وقت داری: بخش **۱ (محصول)** و **۲ (قوانینِ سخت)** را بخوان — نقضِ بخش ۲
> یعنی خرابیِ حقوقی/اعتمادی، نه فقط باگ.

## ۱) محصول چیست

پلتفرمِ **تحلیل ریسک و طراحی پرتفوی** برای بازار سرمایهٔ ایران، ساختهٔ **آرش صفری**
(مشاور سرمایه‌گذاریِ دارای مجوز). هستهٔ فکری: **سامانهٔ پشتیبانِ تصمیم (DSS)**، نه رباتِ
معامله‌گر. یعنی داده و تحلیل می‌دهد تا کاربر خودش تصمیم بگیرد؛ **لایهٔ اجرا/سفارش ندارد.**

تمایزِ اصلی (چیزی که رقبا مثل انیگما/بورس‌ویو ندارند): **صداقتِ دادهٔ اثبات‌پذیر** —
عددِ ناموجود = خالی، بازهٔ ارزش‌گذاری به‌جای قیمت هدف، و «کارنامهٔ هش‌زنجیره‌ای» از
تحلیل‌های آرش (هنوز ساخته نشده؛ بخش ۱۱).

مخاطب: سرمایه‌گذارِ ایرانی. کلِ UI **فارسی و راست‌به‌چپ** است.

## ۲) قوانینِ سخت (نقض‌ناپذیر)

اینها از `~/.claude/CLAUDE.md` (شخصیِ آرش) و `CLAUDE.md`ِ ریپو می‌آیند و **بر هر چیزِ دیگر
اولویت دارند**:

1. **هیچ عدد/آمار/درصد/تستیمونیالِ ساختگی.** دادهٔ واقعی و اثبات‌پذیر یا **`null`**. این
   یک مسئولیتِ **حقوقی** است، نه سلیقه. (کلِ تصمیمِ اخیرِ ما دربارهٔ درج‌نکردنِ یک عددِ
   PSY مشکوک از همین‌جا آمد — بخش ۸.)
2. **هیچ سود تضمینی/وعدهٔ بازدهی**، نه صریح نه تلویحی.
3. **واژه‌های «سیگنال/خرید/فروش/توصیه/پیشنهاد» در هیچ خروجیِ UI یا متنِ تولیدی مجاز نیست.**
   (این DSS است، نه توصیه‌گر.) «تحلیل» بگو.
4. **ارزش‌گذاری همیشه بازه + فروض (سه سناریو)** — هرگز قیمت هدفِ واحد.
5. **جدول‌های داده append-only / نسخه‌دار.** `UPDATE`/`DELETE`ِ مخرب که رکوردِ قبلی را
   نابود کند ممنوع (به‌ویژه `codal_reports`, `symbol_history`, `signals`, `fx_heavy_analytics`).
6. **سکرت‌ها هرگز چاپ/کامیت نشوند.** فقط `.env` و placeholder. `admin.ts` (سرویس‌رول)
   **هرگز** در کامپوننتِ کلاینت import نشود (کلید لو می‌رود).
7. **بدون اجازهٔ صریحِ آرش در همان جلسه: push/PR/deploy نکن.** تغییر را اعمال و **local
   کامیت** کن؛ منتظرِ okِ او بمان.
8. **ویرایشِ جراحی.** فقط همان چیزی که تسک خواسته؛ به تم/چیدمان/منطقِ نامرتبط دست نزن.
   قبل از بازنویسیِ گسترده/rename/افزودن dependency بپرس.
9. **پاسخ‌ها فارسی.** اصطلاحِ فنیِ انگلیسی را بارِ اول یک‌خطی معنی کن (آرش مشاور است، نه
   توسعه‌دهنده).
10. **قبل از کار روی DSS/ترمینال/کوانت** → `docs/DSS-STATE.md` را بخوان.
    **قبل از کار روی داده/رله/نماد/صندوق/NAV/کدال** → `.claude/skills/iran-market-data/SKILL.md`.

## ۴) معماری — سه اصلِ کلیدی

**الف) «یک موتور، دو نما».** همهٔ محاسباتِ هسته فقط در `lib/core/engine.ts` (و دوستانش در
`lib/core/`) است. ترمینالِ ادمین و صفحاتِ عمومی **هر دو از همان می‌خوانند** — منطق دوباره
نوشته نمی‌شود. هر تابعِ هسته **قبل از UI تست دارد**: `npm run test:core` و `npm run test:calc`
(node:test + tsx). **VERIFIED (2026-07-25، روی `main`):** `test:core` = ۲۳۸ تست سبز،
`test:calc` = ۶۵ تست سبز (مجموع ۳۰۳)، هر دو با ۰ شکست.

**ب) سه‌گانهٔ Supabase (اشتباه نگیر):**
- `lib/supabase/client.ts` → کامپوننتِ کلاینت (مرورگر، کلیدِ anon).
- `lib/supabase/server.ts` → RSC و route handler (با کوکیِ کاربر).
- `lib/supabase/admin.ts` → **service-role**، `server-only`، RLS را دور می‌زند. فقط برای
  verifyِ پرداخت و وبهوکِ تلگرام و نوشتنِ سرور. **هرگز در کلاینت import نشود.**

**ج) جریانِ داده:**
```
BrsApi (داخل ایران) ──> رلهٔ Liara (relay/server.mjs) ──> Supabase (جدول‌های append-only)
                                                              │
                              سایتِ Vercel (RSC) ─── می‌خواند ─┘ ─── نمایش به کاربر
```
Authِ مسیرها در `middleware.ts`: `/dashboard`، `/admin`، `/terminal` گیت می‌شوند؛ نقشِ
admin از `profiles.role` در دیتابیس خوانده می‌شود (منبعِ واحدِ حقیقت).

**چیست:** یک «ابر داشبوردِ اقتصادسنجیِ نرخ ارز»، **ادمین‌فقط**. نسخهٔ TypeScriptِ یک داشبوردِ

**دو نیمه:**

- **نیمهٔ سبک (زنده، در مرورگر) — کامل و تست‌شده.** `lib/fx/engine.ts`: PPP چندپایه،
  مدل پولی (+سرعت گردش)، فرنکل–بیلسون (سری)، ترکیبِ هندسی، حباب، پیش‌بینیِ رو به جلو،
  حساسیت (نفت/کسری/heatmap/تورنادو). **۲۶ تستِ عددیِ طلایی** مقابلِ خروجیِ پایتونِ آرش
  (`lib/fx/engine.test.ts`). دادهٔ کلان از `lib/fx/data/*.json` (سالانه/ماهانه)، نرخِ زندهٔ
  دلار از `fx_rates`. صفحه: `app/(protected)/admin/fx/page.tsx` → `components/admin/AdminFxDashboard.tsx`.
  آپلودِ اکسل از خودِ سایت (`FxSeedManager` → `ir_market_snapshots`).
