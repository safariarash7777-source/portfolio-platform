## بازبینیِ نسخهٔ ۱٫۱ — چه چیزی اصلاح شد

نسخهٔ اولِ این نمونه چند عددی را نشان می‌داد که **دادهٔ واقعی پشتشان نیست**.
برای یک نمونهٔ طراحی این خطرناک‌تر از حالتِ خالی است: بازبین فرض می‌کند آن
بخش شدنی است و رویش تصمیم می‌گیرد.

### دورِ دومِ بازبینی — ایرادِ حسابیِ جدولِ محصولات

بازبینِ بعدی درست گفت که «تأییدِ حبابِ +۵٪» پاسخِ ایرادِ جدولِ محصولات نبود.
آن جدول بررسی شد و **چهار ایرادِ حسابی** داشت:

| ایراد | شاهد | اصلاح |
|---|---|---|
| **مبلغِ ردیفِ اول دقیقاً نصف بود** | ۱۷٬۹۰۰ × ۶۲۰ = **۱۱٬۰۹۸** هزار م.ر، ولی **۵٬۵۴۹** نوشته شده بود — نسبت دقیقاً **۲٫۰۰×**. ردیفِ دوم دقیقاً درست است (۹٬۳۰۰ × ۵۹۰ = ۵٬۴۸۷، نسبت ۱٫۰۰×)، پس اتحاد عمدی است و فقط ردیفِ اول می‌شکندش | مبلغ به ۱۱٬۰۹۸ اصلاح شد |
| **سهمِ صادرات با هیچ خوانشی نمی‌خواند** | KPI ۳۸٪ · از مبالغِ قبلی ۳۹٫۸٪ · از مبالغِ درست ۵۶٫۹٪ | به **۵۷٪** اصلاح و مبنایش روی کارت نوشته شد |
| **شکافِ تولید و فروش با تناژِ همان جدول نمی‌خواند** | (۶۸٬۴۰۰ − ۶۹٬۵۰۰) ÷ ۶۹٬۵۰۰ = **−۱٫۵۸٪**، ولی −۴٪ نوشته شده بود | به **−۱٫۶٪** اصلاح و مبنایش نوشته شد |
| **«م.ت» دو معنای متفاوت داشت** | در کارتِ صندوق «میلیون تومان» و در فروشِ ماهانه زیرنویس «میلیارد تومان» — و جمعِ جدول (۱٬۹۴۹٫۵ میلیارد تومان) با هیچ‌کدام نمی‌خواند | مخفف حذف شد؛ واحد روی هر عدد کامل نوشته می‌شود و «فروش مرداد» = **۱٬۹۵۰ میلیارد تومان** که جمعِ همان جدول است |

زیرِ جدول حالا یک **اتحادِ قابلِ بررسی** نوشته شده تا بازبین بتواند خودش
حساب کند: `مقدارِ فروش × نرخ = مبلغ`، و جمعِ ستونِ مبلغ با کارتِ «فروش مرداد»
یکی است.

> اعدادِ باقی‌مانده همچنان **نمایشی**‌اند و بنرِ بالای صفحه همین را می‌گوید.
> فرقِ این نسخه: هیچ عددِ نمایشی، قابلیتی را وعده نمی‌دهد که داده‌اش وجود ندارد.

## فایلِ نمونه

`market-core-prototype.html` — یک فایلِ مستقل و بدونِ وابستگی. در مرورگر باز کنید.
توکن‌های رنگ عیناً از `app/globals.css` آمده‌اند تا نمونه با محصول یکی باشد.

با نوارِ بالای صفحه می‌توان عوض کرد: **صفحه** (خانهٔ عضو / صندوق / نماد) ·
**اندازه** (دسکتاپ / موبایل) · **حالتِ داده** (کامل / ناقص / کهنه / خطا) · **تم** (روشن / تیره).

لینکِ مستقیم به یک حالت هم کار می‌کند:

```
market-core-prototype.html#fund/mobile/stale/dark
market-core-prototype.html#symbol/partial
```

## چطور بازتولید کنم

```bash
/opt/pw-browsers/chromium --headless --no-sandbox --disable-gpu --hide-scrollbars \
  --window-size=1440,1300 --virtual-time-budget=2500 \
  --screenshot=out.png \
  "file://$PWD/docs/assets/design-review/market-core-prototype.html#fund"
```

> **دامِ شناخته‌شده:** Chromiumِ headless کمینه‌عرضِ viewport ≈ ۴۸۵px دارد.
> برای عکسِ موبایل، `--window-size=800,…` بدهید و در hash کلیدواژهٔ `mobile` را بگذارید
> تا از قابِ شبیه‌سازِ ۳۹۰px استفاده شود. عکس‌گرفتن با `--window-size=390` تصویرِ
> بریده و جابه‌جا می‌دهد — این یک artifactِ عکس‌برداری است، نه باگِ چیدمان.
