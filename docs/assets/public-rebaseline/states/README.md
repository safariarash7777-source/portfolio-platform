# حالت‌های پنلِ بازار — شواهدِ بصری

این تصاویر از **کدِ همین شاخه** و بیلدِ Production محلی گرفته شده‌اند، در
۱۴۴۰×۹۰۰.

## ⚠️ اعدادِ داخلِ این تصاویر واقعی نیستند

برای دیدنِ حالت‌هایی مثل «کهنه» باید پاسخِ `/api/market` کنترل شود، پس پاسخ با
یک **فیکسچر** جایگزین شده است. اعداد عمداً به شکلِ `۱۱۱۱۱۱…` انتخاب شده‌اند تا
هیچ‌کس آن‌ها را با قیمتِ واقعی اشتباه نگیرد.

این فیکسچرها **فقط** برای گرفتنِ همین تصاویر استفاده می‌شوند. هیچ‌کدام واردِ
محصول نمی‌شوند و هیچ عددی به بازدیدکننده نشان داده نمی‌شود که از منبعِ واقعی
نیامده باشد.

## چطور گرفته می‌شوند (و یک اشتباهِ اصلاح‌شده)

تصویر از **خودِ کارت** گرفته می‌شود، نه از یک ناحیهٔ مختصاتی.

نسخهٔ اولِ این تصاویر با `boundingBox()` کلیپ می‌شد؛ آن اندازه پیش از نشستنِ
داده خوانده می‌شد، پس ارتفاع فقط به‌اندازهٔ تیتر بود و هر شش تصویر یک نوارِ
خالی شدند — سه‌تایشان بایت‌به‌بایت یکسان. تصویری که ادعا کند «حالتِ کهنه» را
نشان می‌دهد ولی چیزی جز عنوان نداشته باشد، از نبودِ تصویر بدتر است. اصلاح شد و
هش‌ها حالا متفاوت‌اند (به‌جز خالی/خطا که عمداً یکسان‌اند).

## `07` — باگی که اصلاح شد

پاسخِ `/api/market` **دو** مهرِ زمانی دارد: `fetchedAt` (ساعتِ CoinGecko) و
`ir.fetchedAt` (ساعتِ رله). سطحِ عمومی فقط اولی را می‌خواند و همان را کنارِ
قیمتِ دلار و سکه می‌نوشت.

یعنی اگر رله می‌خوابید ولی CoinGecko جواب می‌داد، برچسب «به‌روزرسانی: هم‌اکنون»
می‌ماند در حالی که قیمتِ دلار ساعت‌ها کهنه بود.

`07` همان حالت است: دادهٔ ایران ۱۸۰ دقیقه، دادهٔ جهانی صفر دقیقه. سرصفحه حالا
**«دادهٔ کهنه · ۱۸۰ دقیقه پیش»** می‌گوید و نقطهٔ «زنده» را برنمی‌دارد.

قاعده در `lib/market-freshness.ts`: فقط مهرِ زمانیِ منابعی که **واقعاً رندر
شده‌اند** حساب می‌شود و **قدیمی‌ترین**شان گزارش می‌شود.

> ⚠️ فیکسچرِ نسخهٔ قبل `ir.fetchedAt` نداشت — یعنی شکلِ پاسخِ واقعی را مدل
> نمی‌کرد. فیکسچری که شکلِ واقعی را ندارد، حالتِ واقعی را هم اثبات نمی‌کند.
> اصلاح شد.

## `08` و `09` — نوارِ قیمت

`08` با منبعی گرفته شده که **۲۸ ردیف** می‌دهد (۱۵ ارز، ۹ قلمِ طلا، ۴ جهانی).
نوار **۱۲** تای اولویت‌دار را نشان می‌دهد؛ بقیه رد می‌شوند. دادهٔ کامل در
`/market` دست‌نخورده است — اینجا فقط انتخاب می‌شود.

`09` همان نوار زیرِ `prefers-reduced-motion: reduce`: کپیِ تکراری ساخته
نمی‌شود، `animation-name: none` است و مختصاتِ نوار در ۱٫۵ ثانیه صفر پیکسل
جابه‌جا می‌شود.

بررسیِ رفتاری: `node scripts/qa-ticker.mjs`.

## چیزی که این تصاویر نشان می‌دهند

- **نقطهٔ «زنده» فقط روی دادهٔ تازه است.** روی حالتِ کهنه و قطع‌شده نمایش داده
  نمی‌شود، چون آنجا یک ادعای غلط است.
- **حالتِ خالی و حالتِ خطا یک ظاهر دارند.** این عمدی نیست، محدودیت است: پنل
  وقتی هیچ ردیفی نگیرد نمی‌تواند تشخیص دهد منبع خالی بوده یا نرسیده. تا وقتی
  `/api/market` این دو را از هم جدا نکند، ادعای تفکیک در UI بی‌پایه است.
- **ردیفِ قیمتِ صفر رندر نمی‌شود.** پیش از این، منبعی که `0` می‌داد به‌صورت
  «۰ تومان» ظاهر می‌شد و از دادهٔ واقعی قابلِ تشخیص نبود.
- **درصدِ نامعتبر هم رندر نمی‌شود.** `formatSignedPercent(NaN)` رشتهٔ «• ٪NaN»
  می‌ساخت. گاردِ قیمت این را نمی‌گرفت چون فقط قیمت را می‌سنجید؛ حالا
  `hasRealChange` جداگانه می‌سنجدش. صفر معتبر است — «بدون تغییر» واقعیتِ بازار است.
- **نبودِ نماد با چیزی جایگزین نمی‌شود.** اگر `IR_COIN_EMAMI` در پاسخ نباشد،
  فهرست یکی کوتاه‌تر می‌شود؛ نه صفر پر می‌شود نه دارایی دیگری جایش می‌نشیند.

## شکست‌پذیریِ گاردها اثبات شده است

یک تستِ سبز به‌تنهایی چیزی ثابت نمی‌کند. `scripts/prove-guards.mjs` برای هر
گارد نقصِ واقعی را برمی‌گرداند، انتظار دارد تست **قرمز** شود، بعد گارد را
برمی‌گرداند و انتظار دارد **سبز** شود:

```bash
node scripts/prove-guards.mjs
```

هر شش مورد اثبات شدند. همین اسکریپت یک نقصِ واقعی در خودِ تست‌ها پیدا کرد:
ادعای `aria-hidden` با الگوی `/aria-hidden="true"/` نوشته شده بود و با
برداشتنِ آن از `<ul>` هنوز سبز می‌ماند، چون همان رشته در `<span>`ِ درصدِ تغییر
هم بود. ادعا سفت شد.

## بازتولید

```bash
npm run build
npx next start -p 3111

# در ترمینالِ دیگر
export PLAYWRIGHT_CHROMIUM=/path/to/chrome
export QA_BASE_URL=http://127.0.0.1:3111
node scripts/qa-market-states.mjs   # تصاویرِ ۰۱ تا ۰۷
node scripts/qa-ticker.mjs          # تصاویرِ ۰۸ و ۰۹ + بررسیِ رفتاری
node scripts/prove-guards.mjs       # اثباتِ شکست‌پذیریِ گاردها (سرور لازم ندارد)
```

`playwright` وابستگیِ این مخزن نیست؛ اسکریپت‌ها `playwright-core` را هم قبول
می‌کنند تا روی محیطی که فقط مرورگرِ از پیش نصب‌شده دارد اجرا شوند.
