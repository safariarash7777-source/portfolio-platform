## ⚠️ دادهٔ داخلِ تصاویر فیکسچر است

`/admin/desk` پشتِ گیتِ نقشِ ادمین است و محیطِ محلی هیچ Supabaseای وصل ندارد.
برای عکس‌گرفتن از خودِ میز یک **مسیرِ موقتِ QA** ساخته شد که با یک نوارِ قرمزِ
صریح روی صفحه برچسب خورده بود، و **پیش از کامیتِ نهایی حذف شد** — در درخت
باقی نمانده است.

فیکسچر عمداً آرایه‌های خالی می‌دهد، چون همان چیزی است که باید ثبت شود: حالت‌های
صادقانهٔ «ثبت نشده»، «در دسترس نیست» و «پیکربندی نشده». هیچ عددِ بازار، وزنِ سبد
یا رکوردِ مشتریِ ساختگی در هیچ تصویری نیست.

## آنچه تصاویر اثبات می‌کنند

- **شش پاسخ با حالت‌های متمایز.** «هنوز ثبت نشده» (خالی)، «در دسترس نیست»،
  «پیکربندی نشده» و «آماده» هر کدام برچسب و رنگِ خودشان را دارند. پیش از این
  هر سهٔ اول یک زردِ «نیازمند توجه» بودند.
- **نوارِ تریاژ بالای کارت‌ها.** «۴ پاسخ به دادهٔ ناسالم تکیه دارد — اول همان را
  ببینید» با شمارشِ تفکیک‌شده. کارتِ هم‌وزن دیگر اولین چیزِ صفحه نیست.
- **سبدِ مرجع صادق است.** ۷۰/۱۵/۱۵ با برچسبِ صریحِ «هدف» و زیرش «ابزارِ نماینده
  تعیین نشده»، به‌علاوهٔ چهار پرسشِ مشخصی که از مالک لازم است. هیچ‌جا وانمود
  نمی‌شود که این وضعیتِ زندهٔ سبد است.
- **گیتِ دسترسی کار می‌کند.** ناحیهٔ مشتری و نوارِ سلامت «دسترسی غیرمجاز» و
  «میز خوانده نشد» نشان می‌دهند، چون فیکسچر نشستِ ادمین ندارد و
  `/api/admin/desk` پاسخِ ۴۰۱ می‌دهد. این خرابی نیست — همان fail-closed است.

### دو نقصِ واقعی که همین QA پیدا کرد

۱. **کنتراست.** `--gold` روی سطحِ روشن ۳٫۰–۳٫۲۵:۱ می‌داد و `--danger` روی سطحِ
   تیره فقط **۲٫۳۵:۱** — عملاً ناخوانا. دو توکنِ تازه اضافه شد: `--danger-ink`
   (که با تم می‌چرخد) و `--gold-on-tint` (که عمداً **نمی‌چرخد**، چون
   `--gold-tint` هم نمی‌چرخد و یک جوهرِ چرخان آنجا روشن روی روشن می‌شد).
۲. **`--text-3` روی سطحِ کرم** فقط ۴٫۱۷–۴٫۴۴:۱ می‌دهد. چهار رشتهٔ **معنادار** به
   `--text-2` رفتند. توکنِ مشترک دست نخورد، چون صفحاتِ عمومی (کارِ #116) از آن
   استفاده می‌کنند و این مأموریت حق ندارد آن‌ها را تغییر دهد.

## شکست‌پذیریِ گاردها

```bash
node scripts/prove-guards.mjs
```

هر ۱۱ گارد اثبات شدند — نقص برگردانده می‌شود، تست باید **قرمز** شود، گارد
برمی‌گردد و باید **سبز** شود. پنج موردِ تازهٔ این مأموریت:

```
✓ تفکیکِ تصمیمِ انسانی از خرابیِ داده
✓ خرابیِ داده بر حالتِ انسانی غالب است
✓ سبدِ مرجع تا تصمیمِ مالک fail-closed می‌ماند
✓ یک نقطهٔ شروعِ داخلی
✓ تریاژ خرابی را اول می‌گذارد
```

برای بازتولید باید دوباره ساخته و بعد حذف شود.
