# ممیزی تجربه عمومی دیده‌بانی بازار

**تاریخ:** ۱۱ مرداد ۱۴۰۵  
**شاخه:** `audit/public-market-ux-review`  
**محدوده:** ۹ مسیر عمومی — بدون دسترسی به پنل ادمین، Agent، دیتابیس، پرداخت یا Secret

---

## وضعیت کلی

همه ۹ مسیر بررسی‌شده در وضعیت **عملیاتی** هستند. داده واقعی نمایش می‌دهند، empty/error state دارند، RTL و Dark Mode پشتیبانی می‌کنند، و هیچ ادعای تأییدنشده‌ای در محتوای سایت وجود ندارد. پنج مورد نیازمند اصلاح شناسایی شد که در جدول زیر آمده است.

## مشکلات شناسایی‌شده

### M1 — SEO title صفحه `/market` خیلی کوتاه
**وضعیت:** ناقص  
**شدت:** متوسط  
**توضیح:** `<title>رصد بازار · آرش صفری</title>` — بخش اول فقط ۹ کاراکتر است. Google معمولاً عنوان‌های ۵۰-۶۰ کاراکتری را ترجیح می‌دهد.  
**پیشنهاد اصلاح:**
```ts
// app/market/page.tsx
export const metadata: Metadata = {
  title: 'رصد بازار سهام ایران — شاخص، صندوق‌ها و اختیار معامله · آرش صفری',
  description: 'داشبورد زنده بازار سهام ایران: شاخص کل، هم‌وزن، نقشه بازار، دیده‌بان صندوق‌ها و تابلوی اختیار معامله — به‌روز شده روزانه.',
}
```

### M2 — SEO description صفحه `/market` کوتاه
**وضعیت:** ناقص  
**شدت:** متوسط  
**توضیح:** description فعلی ۵۳ کاراکتر است. توصیه Google: ۱۲۰-۱۶۰ کاراکتر.  
**پیشنهاد:** در M1 ادغام شده است.

### M3 — `/market/options` در footer نیست
**وضعیت:** ناقص  
**شدت:** کم  
**توضیح:** Footer.tsx لینک به `/market/options` ندارد. کاربر فقط از طریق navbar می‌تواند به این صفحه برسد.  
**پیشنهاد اصلاح:**
```tsx
// components/layout/Footer.tsx — در بخش «بازارها»
{ label: 'تابلوی اختیار معامله', href: '/market/options' },
```

### M4 — disclaimer برای محتوای شبکه اجتماعی در `/insights`
**وضعیت:** پیشنهادی  
**شدت:** متوسط  
**توضیح:** برخی پست‌های تلگرام حاوی عباراتی مثل «خرید طلا توصیه می‌شود» هستند. این محتوای واقعی از شبکه اجتماعی است (نه ادعای سایت)، اما یک disclaimer کوچک در بالای صفحه می‌تواند ابهام را رفع کند.  
**پیشنهاد اصلاح:**
```tsx
// app/insights/page.tsx — زیر description
<p className="text-xs text-muted-foreground mt-2">
  محتوای این صفحه مستقیماً از شبکه‌های اجتماعی آرش صفری بازنشر می‌شود و توصیهٔ سرمایه‌گذاری نیست.
</p>
```

### M5 — ogImage/openGraph metadata در همه صفحات تعریف نشده
**وضعیت:** پیشنهادی  
**شدت:** کم  
**توضیح:** هیچ‌یک از ۹ صفحه `openGraph.images` ندارند. اشتراک‌گذاری در تلگرام و واتساپ بدون تصویر پیش‌نمایش ضعیف‌تر است.  
**پیشنهاد اصلاح:** یک `opengraph-image.tsx` پیش‌فرض در `app/` ایجاد شود که از Next.js ImageResponse استفاده کند.

## نقاط قوت تأییدشده

همه ۹ صفحه از design tokens یکسان (`var(--bg)`، `var(--navy-deep)`، `font-display`) استفاده می‌کنند و هماهنگی بصری با صفحه اول جدید (PR #102) کامل است. RTL در root layout تعریف شده و همه صفحات خودکار RTL هستند. Empty state در همه صفحات صادقانه و بدون عدد ساختگی است. timestamp تازگی داده در همه صفحات بازار نمایش داده می‌شود. هش زنجیره‌ای SHA-256 در `/analyses` واقعی و پیاده‌سازی‌شده است. سلب مسئولیت در صفحات `/analyses`، `/codal` و `/insights` حاضر است.

## محدوده ممنوع (بررسی‌نشده)

بر اساس دستورالعمل Command Center، موارد زیر از محدوده این ممیزی خارج بودند:

- پنل ادمین و Arash Desk (`/admin/desk`)
- Agent یا LLM
- Migration و دیتابیس
- پرداخت و Entitlement
- تغییر Secret یا Environment
- حذف صفحات تحلیلی یا SEO
