# تسک: راه‌اندازی «رلهٔ بازار ایران» + اتصال به سایت

**کارفرما:** آرش صفری · **ریپو:** `safariarash7777-source/portfolio-platform` · **زمان تخمینی:** ۳۰–۴۵ دقیقه
**پیش‌نیازها:** دسترسی به یک حساب هاست ایرانی (ترجیحاً لیارا) و دسترسی به تنظیمات پروژهٔ Vercel کارفرما (یا انجام مرحلهٔ ۴ توسط خود کارفرما).

---

## ۱) زمینه — چرا این کار لازم است؟

سایت روی **Vercel (سرورهای خارج از ایران)** میزبانی می‌شود. همهٔ منابع دادهٔ بازار ایران
(tgju ،fipiran ،brsapi و…) درخواست‌های با IP خارجی را **403** می‌دهند — این تست شده و قطعی است.
پس سایت نمی‌تواند مستقیم قیمت طلا/ارز/صندوق بگیرد.

راه‌حل: یک **سرویس رلهٔ خیلی کوچک داخل ایران** که داده را از منابع داخلی می‌کشد و با یک
endpoint ساده به سایت می‌دهد. **کد این رله کامل نوشته و تست شده** و در پوشهٔ `relay/` ریپو است.
کار شما فقط دیپلوی و اتصال است — نه نوشتن کد.

## ۲) آنچه در ریپو آماده است

| فایل | توضیح |
|---|---|
| `relay/server.mjs` | کل سرویس؛ Node خام (≥18)، **بدون هیچ وابستگی**، بدون build |
| `relay/package.json` | فقط `npm start` → `node server.mjs` |
| `relay/README.md` | راهنمای خلاصهٔ همین تسک |
| `lib/market-ir.ts` (سمت سایت) | از قبل آماده؛ با ست‌شدن دو env در Vercel خودکار وصل می‌شود |

**رفتار سرویس:**
- `GET /healthz` → متن `ok`
- `GET /market.json` → JSON با ساختار:
  ```json
  {
    "gold":     [{ "id": "geram18", "faName": "طلای ۱۸ عیار", "price": 4823000, "unit": "toman", "change": 1.2 }],
    "currency": [{ "id": "price_dollar_rl", "faName": "دلار آمریکا", "price": 92500, "unit": "toman", "change": -0.4 }],
    "funds":    [{ "id": "fund-11111", "faName": "صندوق طلای …", "price": 98700, "unit": "toman", "change": 0.8 }],
    "stocks":   [],
    "fetchedAt": 1783800000000
  }
  ```
- منابع: tgju (طلا/سکه/ارز — ریال به تومان تبدیل می‌شود) و fipiran (۸ صندوق طلای بزرگ).
- کشِ ۵ دقیقه‌ای داخلی دارد؛ اگر منبعی جواب ندهد همان بخش `[]` می‌ماند (کرش نمی‌کند).
- اگر env با نام `RELAY_TOKEN` ست شود، فقط درخواست‌های دارای هدر
  `Authorization: Bearer <token>` جواب می‌گیرند (بقیه 401).

## ۳) شرح کار

### مرحلهٔ ۱ — دیپلوی روی هاست ایرانی
1. در [liara.ir](https://liara.ir) یک برنامهٔ **NodeJS** بسازید (کوچک‌ترین پلن کافی است). هاست ایرانی دیگر هم قابل قبول است؛ **شرط: سرور داخل ایران باشد.**
2. فقط محتوای پوشهٔ `relay/` را دیپلوی کنید (همان دو فایل).
3. یک توکن قوی بسازید و به‌عنوان env ست کنید:
   ```bash
   openssl rand -hex 24   # خروجی = RELAY_TOKEN
   ```
   - `RELAY_TOKEN=<خروجی بالا>`
   - پورت را خود پلتفرم با `PORT` می‌دهد؛ کد آن را می‌خواند.

### مرحلهٔ ۲ — تست پذیرش رله (از داخل ایران)
```bash
# 1) سلامت
curl https://<app>.liara.run/healthz
# انتظار: ok

# 2) بدون توکن
curl -i https://<app>.liara.run/market.json
# انتظار: HTTP 401

# 3) با توکن
curl -H "Authorization: Bearer <RELAY_TOKEN>" https://<app>.liara.run/market.json
# انتظار: HTTP 200 و JSON که در آن gold و currency «غیرخالی» باشند
#         (funds ممکن است چند ثانیهٔ اول خالی باشد؛ یک‌بار دیگر بعد از ۱ دقیقه بزنید)
```
⚠️ اگر `gold`/`currency` خالی ماند یعنی ساختار پاسخ tgju تغییر کرده — لاگ برنامه را ببینید
(پیام `relay error:` یا سکوت). نگاشت کلیدها در `server.mjs` بخش `TGJU_GOLD/TGJU_CURRENCY` است و اصلاحش چند خط بیشتر نیست.

### مرحلهٔ ۳ — اتصال سایت (Vercel)
در پروژهٔ Vercel → **Settings → Environment Variables** (محیط Production) این دو را اضافه و سپس **Redeploy** کنید:

| نام | مقدار |
|---|---|
| `IR_MARKET_RELAY_URL` | `https://<app>.liara.run` (بدون `/` انتهایی، بدون `/market.json`) |
| `IR_MARKET_RELAY_TOKEN` | همان `RELAY_TOKEN` |

### مرحلهٔ ۴ — تست پذیرش نهایی روی سایت
1. `https://<دامنهٔ سایت>/api/market` را باز کنید → در JSON، فیلد `ir` باید `gold` و `currency` غیرخالی داشته باشد.
2. صفحهٔ اصلی سایت:
   - نوار متحرک قیمت زیر hero باید **دلار/طلا (تومان)** را هم نشان دهد، نه فقط کریپتو.
   - در بخش «بازار، همین حالا — زنده» تب‌های **«طلا و سکه»، «ارز»، «صندوق‌ها»** ظاهر شده باشند و عدد واقعی نشان دهند.
3. اعداد باید با ارقام فارسی و واحد «تومان» باشند (تبدیل ریال→تومان درست باشد؛ مثلاً دلار ~عدد پنج‌رقمی تومانی، نه شش‌رقمی ریالی).

## ۴) معیار تحویل (Definition of Done)
- [ ] هر ۴ تست مرحلهٔ ۲ پاس شود (اسکرین‌شات خروجی curl ضمیمه شود)
- [ ] تست‌های مرحلهٔ ۴ روی سایت production پاس شود (اسکرین‌شات صفحه ضمیمه شود)
- [ ] مقدار `RELAY_TOKEN` فقط در env لیارا و Vercel باشد — در هیچ فایل/کامیت/پیامی نوشته نشود
- [ ] آدرس رله و نام برنامهٔ لیارا به کارفرما اعلام شود

## ۵) خارج از محدودهٔ این تسک
- دست‌زدن به هر کد دیگری از سایت (فقط env ست می‌شود)
- تب «سهام»: نیازمند کلید سرویس [brsapi.ir](https://brsapi.ir) است — تسک جداگانه؛ در `relay/server.mjs` تابع `fetchStocks()` جای افزودنش مشخص است
- هرگونه scraping از etfbaz یا tradersarena

## ۶) نکات
- رله هیچ دادهٔ کاربر/سکرت پروژه را ندارد و نمی‌بیند؛ فقط قیمت‌های عمومی.
- اگر لیارا در دسترس نبود: آروان‌کلاد/پارس‌پک/هر VPS ایرانی با Node 18+ هم قابل قبول است (`node server.mjs` + یک reverse proxy با HTTPS).
- سؤال فنی دربارهٔ کد رله بود → کامنت‌های `relay/server.mjs` کامل است.
