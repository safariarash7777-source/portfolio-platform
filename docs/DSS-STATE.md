# DSS-STATE.md — وضعیت و فازهای «قطب‌نمای بازار» (سند زندهٔ اجرایی)

> این سند برای Claude Code و هر ایجنت دیگری است تا بداند **داریم چه می‌سازیم، کجاییم، و بعدش چیست**.
> با هر مرحلهٔ مهم به‌روزرسانی می‌شود. قوانین ریپو در `CLAUDE.md` ریشه؛ نقشهٔ کلان در `docs/ROADMAP-TERMINAL.md`.
> آخرین به‌روزرسانی: ۱۴۰۵/۰۴/۲۶ (پایان ابرتسک «پاک‌سازی و تثبیت»).

## ۱) چه می‌سازیم

**قطب‌نمای بازار** = سامانهٔ پشتیبان تصمیم (DSS) بازار سرمایهٔ ایران با زیرساخت کوانت — **ربات معامله‌گر نیست، لایهٔ اجرا ندارد**. اصل معماری: **«یک موتور، دو نما»** — همهٔ محاسبات در `lib/core/engine.ts` است و هم ترمینال تحلیلگرِ محافظت‌شده و هم صفحات عمومی نماد از همان موتور تغذیه می‌کنند.

## ۲) قوانین غیرقابل‌نقض (TERMINAL-ANALYST laws)

1. ارزش‌گذاری **همیشه بازه + فروض** (سناریوی محافظه‌کارانه/پایه/خوش‌بینانه) — هرگز «قیمت هدف» واحد.
2. واژه‌های «سیگنال، خرید، فروش، توصیه، پیشنهاد» در **هیچ** خروجی UI یا متن تولیدی مجاز نیست (تضمین‌شده با `vocab.test.ts`).
3. هر امتیاز باید **driver** (چرا) داشته باشد — عدد بدون دلیل ممنوع.
4. دادهٔ ناموجود = `null` صادقانه؛ **هیچ عدد ساختگی**. همهٔ اعداد مالی فقط از کدال یا BrsApi.
5. **ماسک کیفی قبل از LLM**: فقط باندهای کیفی (`qualitativeMask`) به LLM می‌رود؛ عدد خام مالی هرگز.
6. جدول‌های `codal_reports`، `symbol_history`، `signals`، `fx_rates`، `codal_feed` و `index_history` **append-only** هستند (تضمین‌شده با تریگر DB).
7. هر تابع هسته **قبل از UI تست** دارد (node:test + tsx). پوشش فعلی: بیش از ۱۰۰ تست سبز.
8. تک‌کدبیس Next.js — سرویس جداگانهٔ Python/Streamlit نداریم. اسکریپت‌های یک‌بارمصرف استثنا هستند.

## ۳) معماری و جریان داده

```
BrsApi + excel.codal.ir  →  رلهٔ Liara (اپ arsadata، داخل ایران)  →  Supabase (append-only)
                                                                        │
                       Next.js روی Vercel  ←  خواندن server-side  ←────┘
                       ├─ صفحات عمومی نماد  app/symbol/[symbol]
                       └─ ترمینال تحلیلگر    app/terminal/[symbol]  (محافظت‌شده)
```

| جزء | جزئیات |
|---|---|
| رلهٔ Liara | `relay/server.mjs` — هر ۵ دقیقه دادهٔ بازار؛ موتور کدال v3؛ جاب EOD شاخص و تاریخچه؛ درج نرخ دلار. دانلود اکسل کدال فقط از داخل ایران. |
| `ir_market_snapshots` | دادهٔ لحظه‌ای بازار، هر ۵ دقیقه. |
| `codal_reports` | گزارش‌های کدال (ن-۱۰ سود و زیان، ن-۳۰ ماهانه). پارسر بانک/بیمه هم اضافه شده. ستون `data` JSONB. |
| `symbol_history` | سابقهٔ روزانهٔ ۲۰ ساله: OHLCV + ارزش معاملات + حقیقی-حقوقی + `buyer_power`. |
| `signals` | کارنامهٔ راستی‌آزمایی‌پذیر (تحلیل‌ها و چشم‌انداز هفتگی) با هش زنجیره‌ای SHA-256. |

## ۴) ممیزی‌های انجام‌شده (تیر ۱۴۰۵)

- **اسپرینت ۱:** گیت ترمینال (entitlement)، صفحات حقوقی، ادغام ناوبری، جاب روزانهٔ تاریخچه (EOD).
- **اسپرینت ۲:** کارنامهٔ قابل راستی‌آزمایی (هش زنجیره‌ای، append-only) در `/analyses` + واژگان قانونی + پنل مدیریت `/admin/analyses`.
- **اسپرینت ۳:** ادغام دو صفحهٔ نماد (`/symbol`)، کارت «امروز بازار» در `/market`، تفکیک نام واچ‌لیست‌ها.
- **اسپرینت ۴:** پارسر کدال بانک/بیمه (تطبیق‌یافته با اکسل ونوین)، چارت‌های ن-۳۰، جدول `fx_rates` (append-only) + سوییچ ریالی/دلاری، چارت طلا/دلار.
- **ابرتسک رصد بازار (M1-M5):** پهنای بازار، نقشهٔ بازار (Treemap صنایع)، فید زندهٔ کدال (`/codal`)، تاریخچهٔ شاخص.
- **ابرتسک پاک‌سازی (C1-C6):** رفع واژگان ممنوع + تست قرارداد واژگان، ایمن‌سازی Supabase (لغو EXECUTE روی توابع امنیتی)، حذف کد مرده (فملی استاتیک، مسیر legacy کدال)، توکنیزه کردن کامل رنگ‌ها (بدون hex خام در UI)، QA ساخت‌یافته (`BUGS.md`)، و نقشهٔ محصول (`PRODUCT-MAP.md`).
