# DSS-STATE.md — وضعیت و فازهای «قطب‌نمای بازار» (سند زندهٔ اجرایی)

> این سند برای Claude Code و هر ایجنت دیگری است تا بداند **داریم چه می‌سازیم، کجاییم، و بعدش چیست**.
> با هر مرحلهٔ مهم به‌روزرسانی می‌شود. قوانین ریپو در `CLAUDE.md` ریشه؛ نقشهٔ کلان در `docs/ROADMAP-TERMINAL.md`.
> آخرین به‌روزرسانی: تیر ۱۴۰۵ (Jul 2026).

## ۱) چه می‌سازیم

**قطب‌نمای بازار** = سامانهٔ پشتیبان تصمیم (DSS) بازار سرمایهٔ ایران با زیرساخت کوانت — **ربات معامله‌گر نیست، لایهٔ اجرا ندارد**. اصل معماری: **«یک موتور، دو نما»** — همهٔ محاسبات در `lib/core/engine.ts` است و هم ترمینال تحلیلگرِ محافظت‌شده و هم صفحات عمومی نماد از همان موتور تغذیه می‌کنند.

## ۲) قوانین غیرقابل‌نقض (TERMINAL-ANALYST laws)

1. ارزش‌گذاری **همیشه بازه + فروض** (سناریوی محافظه‌کارانه/پایه/خوش‌بینانه) — هرگز «قیمت هدف» واحد.
2. واژه‌های «سیگنال، خرید، فروش، توصیه، پیشنهاد» در **هیچ** خروجی UI یا متن تولیدی مجاز نیست.
3. هر امتیاز باید **driver** (چرا) داشته باشد — عدد بدون دلیل ممنوع.
4. دادهٔ ناموجود = `null` صادقانه؛ **هیچ عدد ساختگی**. همهٔ اعداد مالی فقط از کدال یا BrsApi.
5. **ماسک کیفی قبل از LLM**: فقط باندهای کیفی (`qualitativeMask`) به LLM می‌رود؛ عدد خام مالی هرگز.
6. جدول‌های `codal_reports` و `symbol_history` **append-only** — هرگز UPDATE/DELETE.
7. هر تابع هسته **قبل از UI تست** دارد (node:test + tsx).
8. تک‌کدبیس Next.js — سرویس جداگانهٔ Python/Streamlit نداریم. اسکریپت‌های یک‌بارمصرف (بک‌فیل) استثنا هستند.

## ۳) معماری و جریان داده

```
BrsApi + excel.codal.ir  →  رلهٔ Liara (اپ arsadata، داخل ایران)  →  Supabase (append-only)
                                                                        │
                       Next.js روی Vercel  ←  خواندن server-side  ←────┘
                       ├─ صفحات عمومی نماد  app/symbol/[symbol]
                       └─ ترمینال تحلیلگر    app/terminal/[symbol]  (محافظت‌شده)
```

| جزء | جزئیات |
|---|---|
| رلهٔ Liara | `relay/server.mjs` — هر ۵ دقیقه دادهٔ بازار؛ جاب کدال با `CODAL_ENABLED=1`, `CODAL_PER_CYCLE=6`، تایم‌اوت سخت ۸ دقیقه به‌ازای نماد. دانلود اکسل کدال فقط از داخل ایران ممکن است. دیپلوی رله جداست (Liara CLI)، Vercel آن را نمی‌گیرد. |
| `ir_market_snapshots` | دادهٔ لحظه‌ای بازار، هر ۵ دقیقه. |
| `codal_reports` | گزارش‌های کدال (ن-۱۰ سود و زیان، ن-۳۰ ماهانه). ستون `data` JSONB با قرارداد `lib/fundamental/types.ts`. اعداد به **میلیون ریال**، EPS به ریال. |
| `symbol_history` | سابقهٔ روزانهٔ ۲۰ ساله: OHLCV + ارزش معاملات + خرید/فروش حقیقی-حقوقی + `buyer_power`. تاریخ **میلادی**؛ تبدیل جلالی فقط در لایهٔ نمایش. اسکیما: `sql/terminal_t0.sql`. |

## ۴) انجام‌شده (تأییدشده روی پروداکشن)

- **رلهٔ BrsApi پایدار** (PR #32): BRSAPI_BASE قابل‌تنظیم، ۳ بار retry برای push به Supabase، لاگ موفقیت.
- **خط لولهٔ خودکار کدال کامل کار می‌کند** — دیگر آپلود دستی اکسل نداریم. پارسر ن-۱۰ و ن-۳۰ با گزارش رسمی **شبندر Q1 1404** راستی‌آزمایی شد: درآمد 1,442,603,668 میلیون ریال، سود خالص 169,688,569، EPS=1263 — عیناً مطابق کدال. ۲۳ تست واحد سبز.
- **۵ نماد با دادهٔ بنیادی تأییدشده** روی پروداکشن: فملی، فولاد، شبندر، شپنا، خودرو. صفحهٔ نماد خودکار از Supabase می‌خواند (PR #33).
- **موتور هسته نوشته شد**: `lib/core/engine.ts` — `computeRatios` (حاشیه‌ها، رشد، P/E سالانه‌شده)، `valuationBand` (سناریوهای P/E با بازه+فروض+caveat)، کارت امتیاز سه‌محوره (بنیادی ۴۵٪، روند ۳۰٪، نقدینگی ۲۵٪) با driver برای هر جزء، `qualitativeMask` برای LLM.
- **بک‌فیل ۲۰ ساله کامل شد**: 124,052 ردیف برای هر ۳۵ نماد در `symbol_history` (مثلاً خودرو از 2001، فملی از 2007، همه تا Jul 2026). راستی‌آزمایی: هیچ نماد خالی نیست.
- **گسترش کدال**: env `CODAL_SYMBOLS` روی Liara به ۲۷ نماد غیربانکی تنظیم شد (بانک/بیمه تا ساخت پارسر جدا حذف شدند)؛ رله ریستارت و بلافاصله شروع به درج گزارش‌های جدید کرد.
- **ترمینال تحلیلگر ساخته شد**: `app/(protected)/terminal` (فهرست + صفحهٔ نماد) با گیت ادمین DB-سطح + middleware؛ کامپوننت‌ها: `components/terminal/Scorecard.tsx` (سه‌محور + ارزش‌گذاری + ماسک) و `HistoryChart.tsx` (lightweight-charts). پل داده: `lib/core/terminal.ts`، خواننده: `lib/core/history.ts`. تست‌ها: `lib/core/engine.test.ts` — ۲۳/۲۳ سبز.
- **لایهٔ کوانت T4 (نسخهٔ اول)**: `lib/core/backtest.ts` (هزینه‌های واقعی بازار ایران، بدون look-ahead)، `lib/core/allocation.ts` (سبد چنددارایی + ریبالانس فصلی)، `lib/core/regime.ts` (رژیم بازار بر پایهٔ پهنا)، `lib/core/watchlist.ts` — صفحات `/terminal/watchlist` و `/terminal/allocation`. ۴۱/۴۱ تست سبز (PR #37, #38).
- **موتور کدال v3** (PR #39): فید سراسری با واترمارک + بک‌فیل اولویت‌دار ۲۰۰ نماد پرمعامله؛ وضعیت در Supabase (ماندگار)؛ `relay/codal-engine.mjs`. طراحی: `docs/CODAL-ENGINE-V3.md`. پوشش خودکار رشد می‌کند.
- **لایه‌بندی دسترسی**: `sql/phase11_access_tiers.sql` **اعمال شد** (جدول `entitlements` + RLS)؛ `lib/access.ts` تفکیک بازدیدکننده/ثبت‌نامی/مشاوره/وبینار؛ API ادمین `app/api/admin/entitlements`. گیت middleware و layout هر دو entitlement-آگاه شدند (اسپرینت ۱).
- **بانک دادهٔ عمومی**: `/data` (سهام/صندوق/طلا/ارز) + `/data/[symbol]` با نمودار ۲۰ ساله + CSV. داشبورد صندوق‌ها `/market/funds` با NAV/حباب (۱۴۲ صندوق NAV زنده).
- **اسپرینت ۱ «اعتماد و درآمد»**: گیت `/terminal` در middleware حالا entitlement را می‌بیند (مشتری مشاوره/وبینار دیگر بلاک نمی‌شود)؛ ناوبری یکپارچه (Navbar مشترک در هوم)؛ صفحات حقوقی `/legal/{disclaimer,privacy,terms}` و فوتر بدون لینک مرده؛ جاب EOD روزانه در رله (`pushDailyHistory`) که هر روز معاملاتی بعد از ساعت ۱۴ تهران، همهٔ نمادهای معامله‌شده را با `source=relay_eod` به `symbol_history` می‌افزاید (ریال، دفع تکرار، وضعیت در `/debug`).

## ۷) کارهای فوری بعدی (به‌ترتیب)

1. `lib/core/engine.test.ts` — تست همهٔ توابع engine با اعداد مرجع واقعی (الگو: `calc.test.ts`). اسکریپت `test:core` به package.json.
2. `lib/core/history.ts` — گرفتن N روز آخر `symbol_history` یک نماد، خروجی `HistoryDay[]` مرتب صعودی.
3. صفحات `app/terminal/[symbol]` — محافظت‌شده، سه‌محور + بازهٔ ارزش + نمودار + ماسک کیفی. **بدون واژهٔ سیگنالی.**
4. راستی‌آزمایی بک‌فیل پس از اتمام (شمارش ردیف هر نماد در Supabase).
5. گسترش لیست کدال به ~۱۰۰ نماد روی Liara.
6. پارسر بانک/بیمه.
