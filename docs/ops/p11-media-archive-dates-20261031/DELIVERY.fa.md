# P11.4 — بازهٔ تاریخ ثبت‌شده در آرشیو موجود

**Draft مستقل از main ثابت f93dbdce73ef9e57b8e5eb84af13c4a20034d5bc؛ بدون تغییر main، provider، سهمیه، SQL، route یا حق خصوصی.** P14@dfc07c7 و همهٔ شواهدش فریز هستند. مالک این برش A است: MediaHub، helper/test فعلی رسانه و CSS محدود کنترل‌ها. مرجع وضعیت محصول را root در COMMAND-CENTER نگه می‌دارد؛ این برگ فقط قرارداد و شاهد همین تغییر است.

## مسیر استفاده

همان `/insights`: جست‌وجو/شبکه/نوع ← از و تا «تاریخ ثبت‌شدهٔ قبلی (شمسی)» ← نتایج همان انتخاب ← جزئیات ← بستن/بازخوانی. تاریخ‌ها در همان hash موجود با کلیدهای `from`/`to` کنار `q`/`network`/`kind` نگه داشته می‌شوند؛ layout و پارامترهای نامرتبط پاک نمی‌شوند. پاک‌کردن بازه فقط تاریخ را حذف می‌کند؛ پاک‌کردن همهٔ فیلترها تاریخ را هم پاک می‌کند. hero خارج از فیلتر در بازهٔ فعال نمایش داده نمی‌شود.

صفحه یا آرشیو موازی ساخته نشده است. `/design/media` نیز همان MediaHub را با snapshot قدیمی خودش نمایش می‌دهد؛ دادهٔ تاریخ‌دار مصنوعی به runtime یا Preview وارد نشده است.

## معنای تاریخ و حد پوشش

- فقط `published_at` **legacy** که در قرارداد موجود «تاریخ ثبت‌شدهٔ قبلی» خوانده می‌شود، در صورت timestamp معتبر و دارای timezone قابل مقایسه است. این نام قدیمی فیلد، شاهد انتشار معتبر منبع نیست؛ UI همچنان انتشار و آخرین همگام‌سازی را تأییدنشده نشان می‌دهد.
- `dateLabel` فقط متن نمایشی است؛ از آن، عنوان، موضوع، پیوند، روز دریافت snapshot یا زمان امروز هیچ تاریخ ماشینی ساخته نمی‌شود. null و ورودی اصلی تغییر نمی‌کنند. ساعتِ مبهم، date-only، مقدار نامعتبر یا عدد به تاریخ قطعی تبدیل نمی‌شود.
- مرز کاربر تاریخ شمسی است. `toLatinDigits`، `jalaliYmdToGregorian` و `formatJalali` موجود بازاستفاده شده‌اند. helper عمومی جلالی تغییر نکرد؛ اعتبار روز/ماه/اسفند با roundtrip واقعی در helper رسانه بررسی می‌شود. محدودهٔ converter موجود۱۳۰۰ تا۱۵۰۰ است.
- روز timestamp و مقایسهٔ بازه صریحاً Asia/Tehran و مستقل از timezone دستگاه است. هر دو مرز روز شامل‌اند؛ بازهٔ یک‌روزه و بازهٔ یک‌طرفه مجازند. ورودی ناقص/نامعتبر یا شروع بعد از پایان، پیام و حالت خطا می‌دهد؛ فیلتر بی‌صدا حذف و نتیجه گسترده‌تر نمی‌شود.
- شمار فاقد تاریخ پس از همان q/network/kind و روی همان زیرمجموعه محاسبه می‌شود. بدون بازه باقی می‌مانند؛ با بازهٔ فعال کنار گذاشته و دلیل/شمار صریح نمایش داده می‌شود. عنوان کلیِ «آرشیو خالی» برای این حالت ساخته نشده است.
- route موجود `/insights` از قبل `published_at=null` را حذف و حداکثر۶۰ ردیف را می‌خواند؛ هیچ بخشی از query تغییر نکرده است. این فیلتر محلی روی دادهٔ خوانده‌شده است، **نه جست‌وجوی تمام تاریخ آرشیو**. مجوز محتوای خصوصی نیز از این برش استنتاج نمی‌شود.
- snapshot موجود۱۲ردیف دارد و timestamp هر۱۲ null است؛ برچسب تاریخ متنی دارد. بنابراین آن مسیر فقط شاهد حالت unknown-date است، نه پذیرش نتایج تاریخ‌دار واقعی. اگر Preview نتواند منبع واقعی `/insights` را بخواند، این محدودیت صریح می‌ماند و با fixture جایگزین نمی‌شود.

## بررسی محدود کد

۳۶ بررسی در سه فایل موجود موفق‌اند: `presentation.test.ts`، `global-layout.test.mjs` و قراردادهای public-design. آزمون‌های تازه، ارقام فارسی/عربی/لاتین، روز نامعتبر و کبیسه، ابتدا/انتهای روز تهران، AND همهٔ فیلترها، null/label-only، بازهٔ ناقص/وارونه، پاک‌کردن و حفظ hash، و timezoneهای UTC/Los_Angeles/Tokyo را پوشش می‌دهند. harness موجود MediaHub برای اتصال واقعی props/control callbacks، reload/hashchange، عدم نشت hero و حفظ layout سرور بازاستفاده شده است؛ این harness مرورگر یا شاهد بستن dialog/scroll نیست.

برای hook جدید `useId` یک stub پایدار به همان harness موجود افزوده شد؛ دو شکست اولیه از فقدان این hook در harness بود و پس از اصلاح، همهٔ موارد موجود و تازه موفق شدند. تست‌ها واقعی‌بودن clock انتشار را اثبات نمی‌کنند. نمونهٔ تاریخ‌دار فقط در فایل test است.

```text
node node_modules/tsx/dist/cli.mjs --test lib/media/presentation.test.ts lib/media/global-layout.test.mjs lib/public-design/contracts.test.ts
node node_modules/typescript/bin/tsc --noEmit --incremental false
node node_modules/eslint/bin/eslint.js components/insights/MediaHub.tsx lib/media/presentation.ts lib/media/presentation.test.ts lib/media/global-layout.test.mjs
```

CI و Preview همان source جدا ثبت می‌شوند. پذیرش مرورگریِ تاریخ واقعی، برگشت از جزئیات و reload روی محیط مقصد هنوز باز است؛ موفقیت unit/harness یا READY جای آن‌ها نیست. هیچ دریافت تازه از شبکه اجتماعی، ذخیره، provider، موضوع اختراعی یا تغییر خصوصی در این برش وجود ندارد.
