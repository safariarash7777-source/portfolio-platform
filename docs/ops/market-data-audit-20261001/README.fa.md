# بستهٔ قابل‌تحویل بررسی دادهٔ بازار

- `REPORT.fa.md`: گزارش کامل وضعیت، شواهد، نقص‌ها و حدود قطعیت.
- `DEVELOPER-TASK.fa.md`: تسک مرحله‌بندی‌شده و معیار پذیرش توسعه‌دهنده.
- `READ-ONLY-QUERIES.sql`: queryهای تشخیصی بدون credential و بدون mutation.
- `evidence/`: شمارش‌ها، تاریخ‌ها و metadata فنی قابل‌اشتراک از بررسی.

دادهٔ خام مالی، dump، کلید API، رشتهٔ اتصال، فایل env، رکوردهای کاربران و log خصوصی در این بسته نیستند. فایل‌های دارای پسوند private در پوشهٔ بکاپ مالک به این بسته اضافه نشوند.

این بسته گزارش است؛ هیچ اصلاح سایت، backfill یا migration در اجرای بررسی انجام نشده است. نتایج مربوط به زمان و آدرس اصلی ثبت‌شده در گزارش‌اند؛ برای وضعیت روز بعد باید دوباره query شوند.
