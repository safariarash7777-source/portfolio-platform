# اصلاح محدود فرانت موجود — ۲ اکتبر ۲۰۲۶

**نتیجه:** متن و رفتار همان صفحهٔ اصلی و `/webinars` اصلاح شده‌اند. ترکیب Hero، Method، TwoProducts، بازار و Navbar موجود حفظ شده است. این تحویل جایگزین جهت پیشنهادی PR188 است؛ طرح A/B و Estedad تأیید مالک ندارند و مبنای ادغام نیستند. پذیرش تصویری نسخهٔ جدید هنوز **BLOCKED** است؛ تست کد و build، مشاهدهٔ مرورگر محسوب نمی‌شوند.

## مبنا، نسخه و مالکیت

متن سه ماه، توصیف خدمت اعلام‌شدهٔ مالک است؛ تاریخ، policy D-034، عضویت یا پرداخت Production را فعال نمی‌کند. صفحهٔ وبینار همچنان فهرست رویدادهای موجود را می‌خواند؛ اطلاعات cohort جدید را بدون04 منتشر نمی‌کند. فرم فقط درخواست تماس/وقت را ثبت می‌کند؛ تقویم، ظرفیت، تأیید رزرو و نمایش وضعیت lead جدید در پروندهٔ حساب ساخته نشده‌اند.

منبع و تاریخ مطلب در `InsightsPreview` و مسیر کارنامه در Navbar باقی‌اند. شش گارد ادعای همگانی در `public-claims.test.ts` حفظ شدند؛ فقط آزمونی که حضور هر سه جمله را دقیقاً در Hero اجباری می‌کرد با محل واقعی اطلاعات تطبیق یافت.

## فونت، برند و مقصدها

بدنهٔ Vazirmatn و نگاشت display موجود Pelak در `app/layout.tsx` بدون تغییر است؛ فونت از فایل‌های محلی موجود بار می‌شود. هیچ Estedad یا فایل/بارگذاری فونت جدید ندارد. فایل و مجوز تازهٔ IRANSans بررسی/اضافه نشده؛ مجوز مستقلی برای استفادهٔ تازه از Pelak ادعا نمی‌شود. سرمه‌ای، طلایی، RTL و tokenهای فعلی حفظ شدند؛ letter-spacing منفیِ تیترهای اصلاح‌شده حذف شد تا اتصال حروف فارسی آسیب نبیند.

## شاهد قبل/بعد و محدودیت مشاهده

پیش از ویرایش source ثبت شد، اما درخواست راه‌اندازی اجرای محلی توسط بازبینی خودکار ابزار **پیش از ایجاد process** رد شد: `blocked by policy`؛ دلیل جزئی‌تری داده نشد. این راه‌اندازی با ابزار، فرمان یا مسیر دیگر تکرار نشد. در نتیجه URL محلی فعال این نسخه، تصویر «بعد»، بررسی واقعی صفحه‌کلید و اندازه‌های390/1440 برای این diff **UNKNOWN/BLOCKED** هستند. موفقیت build این محدودیت را رفع نمی‌کند.

منبع تاریخی: `portfolio-next-05/docs/ops/seasonal-program/next-05-evidence`؛ SHA `f6cb560478d51d48dcee2c9b2801eb047f5c7214`؛ URL ثبت‌شدهٔ قبل `http://127.0.0.1:8780`. diff فایل‌های landing/layout، app/page، globals و layout میان f6cb و51fd خالی است؛ **source خانه برابر است، پاسخ داده و مشاهدهٔ تازهٔ مرورگر برابر/اثبات‌شده نیستند**. تصاویر webinar قبلی مبنای دقیق این شاخه نیستند چون source آن صفحه میان دوSHA فرق دارد. عبارت اولیهٔ public-rebaseline در فایل ثبت source، انتخاب مقدماتی بود؛ تصاویر نهایی این گزارش همان NEXT05 بالا هستند.

پس از فراهم‌شدن اجرای مجاز، اپراتور همان صفحات `/`، `/#waitlist` و `/webinars` را در390×844 و1440×1000 بررسی کند: نبود overflow، خوانایی تیتر/جدول، Tab/Escape/focus، خطای فهرست و فرم، حفظ ایمیل، retry و رسید بدون ادعای رزرو. fixture باید برچسب‌دار و endpoint یا interception صرفاً sandbox باشد؛ ارسال ایمیل آزمایشی به Production جزو این بسته نیست.

## وابستگی Auth و تحویل

ورود مالک روی URL اصلی **OPEN** است. PR179 علاوه بر پیام خطا، Node middleware و حفظ cookie/مهلت را پیشنهاد می‌کند؛ تغییر مسیر خروجی شبکه هنوز روی Vercel پذیرفته نشده است.190 خطای API هویت را503 می‌کند و به‌تنهایی رفع ورود Production نیست. گزارش مستقل `INCIDENT-AUTH-DIRECT-IP-20261002.md` و پیوست تازهٔ فقط‌خواندنی آن، status سالم GoTrue را از شکست Edge جدا می‌کنند؛ correlation و صادرکنندهٔDirectIP نامعلوم‌اند. این شاخه برای پوشاندن حادثه به Auth دست نمی‌زند.

ابزار/مهارت مصرف‌شده: Git و GitHub GET/PR، PowerShell و Node، Next.js و React best practices، دستورهای دادهٔ بازار iran-market-data برای حفظ null/واحد/تازگی، کانکتور Vercel فقط برای metadata و لاگ، CUA برای بستن تب‌های A/B. dependency/plugin نصب نشد. A/B خاتمه یافته؛ این diff محدود به مالک پوسته و بازبین قابل واگذاری است، با گیت تصویری باز.
