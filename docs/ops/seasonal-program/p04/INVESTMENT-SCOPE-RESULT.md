## تغییر قابل بازبینی

`lib/portfolio/investmentScope.ts` یک تابع خالص برای انتخاب زیرمجموعه همان HoldingVersion است. برای **هر قلم** باید allocatable/excluded صریح ثبت شود؛ unknown، انتخاب ناقص، شناسه تکراری/بیگانه، نسخه قدیمی/دیگر، تأیید بدون زمان منطقه‌ای یا آینده و مجموعه بدون دارایی قابل تخصیص مسدود می‌شوند. metadata خروجی نوع مخرج، نسخه دارایی، نسخه قواعد، زمان تأیید عضو و فهرست اقلام منتخب/خارج را حمل می‌کند. فایل/جدول/UUID/version جدید دارایی ساخته نمی‌شود؛ اطلاعات مالی یا نسخه اصلی تغییر نمی‌کند.

ready فقط به معنی مشخص‌بودن مخرج است؛ قیمت و پوشش همچنان از موتور موجود گیت می‌شوند. نمونه ساختگی خانه9000، سرمایه‌گذاری600 و نقد400، با انتخاب صریح خانه خارج، مخرج1000 و فاصله هدف50/50 برابر -100/+100 دارد؛ کل ترازنامه همچنان همان سه قلم است. با قلم سرمایه‌گذاری بی‌قیمت، مقدار قطعی null می‌ماند.

تابع هنوز به UI، API، schema یا اعلان وصل نیست. این مرحله زیرساخت مستقلP04 است و پذیرشP06 یا پیاده‌سازی تصمیم/الگوی تازه نیست. فراخوانی آینده باید پس از canonical owner-only read و رضایت صریح عضو باشد؛ مرورگر نمی‌تواند وضعیت تأیید را برای سرور معتبر اعلام کند. metadata دامنه در هویت محاسبه/اعلان آینده باید لحاظ شود؛ سه شناسه موجود موتور به‌تنهایی تغییر انتخاب دامنه را تمایز نمی‌دهند.
