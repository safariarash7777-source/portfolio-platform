## پذیرش همین نمونه

- نمونه آماده، empty و error به‌وضوح حالت‌های آموزشی‌اند؛ بازگشت به آماده فقط تغییر نمایش است، نه وانمود به اتصال موفق.
- RTL و وزیرمتن، بدون سرریز صفحه در ۳۲۰/۳۹۰ و دسکتاپ؛ جدول عریض فقط داخل ناحیه نامدار اسکرول می‌شود.
- Tab/Shift+Tab، کنترل‌های native، لینک پرش، focus-visible، افشای جزئیات و جابه‌جایی ساختار قابل استفاده باشند.
- prefers-reduced-motion و کنترل کاهش حرکت بررسی شوند؛ عدد/نمودار انیمیشن ندارد.
- یکسان‌بودن dataset با hash و جدول مقادیر، snapshotهای viewport و مقایسه با مرجع موجود ثبت شود. تصاویر full-page مخدوش مرجع پذیرش نمی‌شوند.
- دو URL ثابت روی Preview همان Vercel موجود، با source SHA دقیق؛ بدون تغییر main یا میزبانی/هزینه جدید. انتشار Preview، انتخاب بصری آرش یا پذیرش محصول نیست.
