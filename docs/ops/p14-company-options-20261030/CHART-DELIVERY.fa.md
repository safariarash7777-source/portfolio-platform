## یافتهٔ ورودی و مهار محدود

validator اولیه انتظار داشت نرخ ماه کاملاً غایب null باشد و شکست خورد: `lib/core/monthlyReport.ts` نرخ را فقط روی کلید گزارش‌های موجود می‌سازد. `connectNulls=false` بدون اسلات غایب مانع وصل‌شدن دو سوی گپ نیست. طبق مالکیت، core و چهار component تغییر نکردند.

مهار نمونه: نرخ/مقدار فقط در انتخاب محصول/بازارِ یک سال پیوسته نمایش می‌یابد؛ در گپ نمودار حذف و دلیل و جدول حفظ می‌شود. نمای کل شرکت ماهانه/تجمیعی/ترکیب را نشان می‌دهد؛ برای نرخ باید محصول یا بازار انتخاب شود. ن-۳۰ بنیادی نیز در گپ کنار گذاشته می‌شود. **نقص موتور رفع نشده و پوشش نمودار حالت گپ کامل نیست.** گزارش جعلی ماه مفقود یا null با cast وارد قرارداد عددی نشده است.

adapter P/E برای تمام فصل‌ها اسلات دارد؛ TTM نامعلوم null است و P/E قدیمی به فصل جدید حمل نمی‌شود. HistoryChart فعلی close=null را حذف می‌کند؛ بنابراین ورودی این نمونه close مفقود ندارد و ادعای رفع گپ قیمت نشده است. برچسب‌های داخلی canvas و کاهش حرکت Recharts نیز هنوز نیازمند بررسی‌اند.

## داده و ساخت

۱۲ گزارش ماهانه در دو نیم‌سال، ۱۰ صورت مالی تجمیعی، دو سال مقایسه و ۱۲ روز قیمت تألیفی‌اند؛ در runtime فریز می‌شوند. زمان نسخه آموزشی جای زمان منبع نیست. هیچ API، حساب، دریافت شبکه‌ای، موتور مالی یا اتصال پایگاه ساخته نشده؛ هیچ کتابخانه/وابستگی تازه نصب نشده است. نشان، فونت و توکن رسمی موجود مصرف می‌شوند.

MonthlySalesCharts، QuarterlyCharts، FundamentalCharts و HistoryChart عیناً بازاستفاده شده‌اند؛ اثر فایل‌ها و نسخه نصب‌شده برابر lock در `public/design/company-options/build-manifest.json` ثبت است. builder ورودی سروری/پایگاه/محیطی را در graph مرورگر رد می‌کند.

```text
node node_modules/tsx/dist/cli.mjs public/design/company-options/validate.ts
node public/design/company-options/build.mjs
node node_modules/typescript/bin/tsc --noEmit --incremental false
node node_modules/eslint/bin/eslint.js --no-ignore public/design/company-options/entry.tsx public/design/company-options/chart-data.ts public/design/company-options/validate.ts
```

validator سیزده کنترل پوشش/قرارداد دارد: ده کنترل دادهٔ نمودار، و سه کنترل رفت‌وبرگشت انتخاب‌ها میان دو مسیر، fallback پارامتر نامعتبر و حفظ متن فارسی/جست‌وجوی محدود. این‌ها آزمون تعامل نیستند. next lint فایل‌های public را نادیده می‌گیرد؛ lint مستقیم اجرا می‌شود. img نشان محلی در HTML مستقل عمدی است و اخطار بهینه‌سازی Next باقی می‌ماند.

بازبینی مستقلِ فقط‌کد روی snapshot محفوظ `ab381ad965c81e12da9e5a1511c6636e5d4966d5` یک P2 یافت: لینک تعویض چیدمان، سال/محصول/بازار/افق جاری را حفظ نمی‌کرد. اصلاح بعدی با `query-state.ts` همان انتخاب‌های جاری، سناریو، تب و فیلتر اسناد را میان مسیرها منتقل می‌کند؛ پارامترها با allowlist خوانده و جست‌وجو به ۸۰ نویسه محدود می‌شود. validator دو جهت و برگشت را با انتخاب‌های غیرپیش‌فرض، برابری ورودی مؤثر نمودار و پارامترهای نامعتبر بررسی می‌کند. این برهانِ قرارداد داده است؛ کلیک و رفتار واقعی مرورگر هنوز آزموده نشده‌اند. snapshot، receipt و Preview قبلی حفظ شده‌اند.
