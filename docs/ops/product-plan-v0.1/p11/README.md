## گیت‌ها

1. گیت مستقل: منابع و قرارداد/قالب‌ها قابل بررسی، schema و fixture آفلاین معتبر؛ شاهد در `validation.json`.
2. گیت قرارداد: P00 مالکیت، SHA release، adapter و نگهداری داده را تأیید کند. تا آن زمان instrumentation آماده تعریف است، فعال نیست.
3. گیت اجرا: مجریان در محیط مجاز روی SHA/schema معلوم شواهد سفر کامل بسازند؛ fixture و CI جانشین این مرحله نیستند.
4. گیت عرضه: بررسی مستقل، پذیرش انسانی و تصمیم عرضه از مالک؛ Production و پیام مشتری در این مأموریت مجاز نیست.

هیچ پایلوتی شروع نشده، هیچ هدف کاهش زمان/هزینه تعیین نشده، هیچ تعداد یا موعد پایلوت تصویب‌شده نامیده نمی‌شود. صاحبP11 در همه موج‌ها همین چت است؛ ظرفیت پاسخ‌گو و تأیید انسانی با آرش/P00 مشخص خواهد شد.
