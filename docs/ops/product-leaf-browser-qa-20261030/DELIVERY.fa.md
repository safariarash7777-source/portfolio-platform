# بررسی مستقل رابط با مرورگر موجود

این بسته ابزار آزمون خارج محصول است. مالک B است؛ root بازبینی فنی و تصمیم انتشار را نگه می‌دارد. مسئله، نبود تصویر و شاهد رفتار واقعی برای صفحهٔ عمومی منبع/زمان PR331 و مؤلفهٔ پیگیری پرسش PR357 است. مخاطب، بازبین فنی و سپس آرش در مسیر مصوب است. تکمیل این بسته با پذیرش بصری آرش یا عملکرد حساب و پایگاه داده یکی نیست.

سورس PR356 در `67aeda9ff84fb1d3e936fc39564c0e551b3ff17e` فریز می‌ماند. ده تابع Chrome موجود، بدون تغییر متن رفتار و گیت‌ها در helper مستقل استخراج شده‌اند؛ lineage و guard هر تابع را با Git همان سورس تطبیق می‌دهد. فایل P09، gateway، پروفایل‌های Auth/DB و بستهٔ a2 تغییر نمی‌کنند. بسته و lock و scripts موجود ثابت‌اند. مرورگر نصب یا دانلود نمی‌شود؛ همان فایل موجود پس از تطبیق hash در درخت خصوصی فقط‌خواندنی اجرا می‌شود.

نسخه‌های هدف: PR331 برابر `f12ba71c353e135f83d136105380f20dd59a95e0` و PR357 برابر `7752638842c3f4c8a6984e3ec753a6c92aad80fc` روی base334 برابر `497ae4681783db7aa9bd9339993c36a29e93ed56`. برای هر Preview، رکورد deployment و status موفق GitHub باید همان SHA و نشانی canonical را نشان دهد. branch alias شاهد نسخه محسوب نمی‌شود.

صفحهٔ عمومی فقط با GET/HEAD در همان دامنه، مسیر نماد فولاد، assetهای محدود و دو API خواندنی لازم بررسی می‌شود. تغییر HTTP، دامنهٔ دیگر، ورود یا مسیر غیرمجاز بسته است؛ درخواست مسدودشده و خطاهای واقعی شمارش می‌شوند. پاسخ ناموفق یا نبود داده، با فیکسچر پوشانده نمی‌شود. صفحهٔ مشاوره بدون حساب معتبر BLOCKED می‌ماند؛ هیچ نشست ساختگی برای عبور از حفاظت وجود ندارد.

fallback مجاز PR357 از خود TSX و CSS و فونت‌های همان Git source در temp ساخته می‌شود. props آموزشی مطابق نوع‌ها و الگوهای آزمون موجود هستند؛ banner داخل همهٔ تصویرها «آموزشی، مؤلفهٔ واقعی، دادهٔ مصنوعی؛ نه حساب/DB/خدمت» را روشن می‌کند. callbackها ثبت یا موفقیت سروری را شبیه‌سازی نمی‌کنند. fixture، viewer یا route وارد app محصول نمی‌شود. چهارچوب آزمون صرفاً یک سرور استاتیک موقت loopback با مالکیت همان اجرا است.

خروجی قابل مشاهده: PNGهای عمومی/آموزشی ۱۴۴۰ و ۳۹۰، تعامل واقعی tab، فیلتر و reset، تاریخچهٔ نسخهٔ پاسخ، قفل فیلتر هنگام ویرایش و بازشدن پس از انصراف، تاریخچهٔ لغو رابطه، خطای خواندن بدون شمارش صفر، معیار overflow و manifest SHA/hash. snapshot باید پس از دانلود باز و دیده شود؛ موفقیت screenshot به‌تنهایی تأیید بصری نیست. وضعیت source، CI، browser، review انسانی و انتشار جدا گزارش می‌شوند.

معیار پایان فنی: lineage و policy guard موفق؛ wrapper تک‌job Linux همان SHA؛ نتیجهٔ واقعی هر مسیر یا مانع نام‌دار؛ تطبیق manifest و hash تصویرها؛ مشاهدهٔ تصویرهای ذخیره‌شده؛ پاک‌سازی browser/context/process/temp/server متعلق به همان اجرا. فقط PNG عمومی/آموزشی و receipt امن upload می‌شوند. هیچ screenshot حساب خصوصی، body/headers/session، credential، HAR، trace، video یا storageState ذخیره یا upload نمی‌شود. SQL/Auth/model/collector/Hermes اجرا نمی‌شود. هزینهٔ زیرساخت/داده/مدل تا اندازه‌گیری null است؛ خرید یا سرویس تازه وجود ندارد.
