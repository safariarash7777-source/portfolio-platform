## قرارداد استفاده در این پروژه

- ابتدا CLAUDE.md، مهارت‌های الزامی مخزن و تصمیم‌های فعلی خوانده شوند؛ این مهارت‌ها مکمل‌اند.

- اگر مأموریت کاربر صریحاً اصلاح را مجاز کرده، مراحل توقف/سؤال عمومی skill جای آن مجوز را نمی‌گیرند. پذیرش بصری و گوشی واقعی صادقانه از بررسی کد جدا گزارش شوند.
