## شکاف‌های تصمیم بدون ساخت ID موازی

منبع انتشار/زمان: `publication_date=null` برای شش فایل موجود؛ تاریخ تولید Excel زمان انتشار آمار نیست. باید شاهد اعلام/بازنگری منبع دریافت و به همان mapping اضافه شود؛ تا آن زمان state «publication unknown» حفظ شود. این کار factual است و انتخاب روش D-FX را انجام نمی‌دهد.

تازگی: پنج‌روزه بودن Hermes، SLA تازگی داده نیست. آستانه پنج روزِ quote اخزا همان کنترل موجود است؛ معیار انتشار سری ماهانه/فصلی/سالانه باید طبق تقویم انتشار واقعی نهاد تصویب/ثبت شود. عدد SLA جدید حدس زده نشده است.

بین‌بانکی: منبع و نوع نرخ مستقل از YTM اخزا/Pouya است. انتخاب آن در D-FX-02 باید tenor/دوره مصرف‌کننده را مشخص کند؛ فعلاً داده یا نرخ جایگزین ساخته نمی‌شود.

Google Sheet: slotهای ثبت‌شده ورودی مدل‌اند؛ اتصال تنظیم‌شده اثبات نشده است. نبود اتصال با موفقیت دریافت Excel مخلوط نشود. ورودی‌های user/private وارد prompt یا evidence نمی‌شوند.

## ورودی تصمیم مورد انتظار از آرش

برای هر D-FX فقط شناسه، گزینه، تعریف/منبع مصوب و محدودیت استفاده ثبت شود؛ «برنامه را اجرا کن» انتخاب گزینه یا مجوز انتشار مالی نیست. ابتدا D-FX-01/02 برای گیت تفسیر ECM/FB؛ سپس D-FX-03/04/05/06 برای قرارداد تاریخچه. هیچ گزینه‌ای در این تحویل به حالت approved تغییر نکرد.
