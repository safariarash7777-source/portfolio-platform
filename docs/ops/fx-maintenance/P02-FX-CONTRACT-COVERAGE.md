## SLA پیشنهادی، بدون اختراع deadline

اخزا: همان پنج روز calendar کنترل موجود؛ تعطیلی بازار یا tenor را نرخ بین‌بانکی ننامد. FX/TGJU: آستانه موجود source_health حفظ، تماس تازه انجام نشد. سری کلان: سن snapshot فقط آخرین بررسی را نشان می‌دهد؛ SLA باید از تقویم اعلام و آخرین release اثبات‌شده بیاید. تا publication null/تقویم نامعلوم، freshness «unverified» و complete-model=false. پیشنهاد بازبینی هر پنج روز موجود است، نه تضمین release هر پنج روز.

## قرارداد زمانی و گیت UI

observation period/date، publication/revision date، دریافت سند، تولید report و اجرای Hermes پنج زمان متفاوت‌اند. زمان‌های اجرایی timezone-aware UTC/Tehran و نمایش تاریخ شمسی/میلادی مطابق مصرف‌کننده؛ تاریخ تولید سند را release ندانید. current/future سال کامل نیست؛ تقویم/تناوب ناسازگار یا gap سال رشد معتبر نمی‌سازد.

پذیرش `/admin/fx` فقط بعد P01 با login واقعی مدیر و همان wrapper/داشبورد موجود: هر۱۲تب، guest/member denial، موبایل، fullscreen، refresh، download و خطای/تاخیر iframe. مالک Auth/فرانت همان P01 است؛ این شاخه route یا login نساخت و شاهد183 مستقل را به پذیرش سایت تعمیم نمی‌دهد.
