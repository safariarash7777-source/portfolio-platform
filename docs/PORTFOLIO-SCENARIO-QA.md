# ابزارِ سناریوی سبد — آنچه واقعاً آزموده شد

مسیر: `/tools/portfolio-scenario` · موتور: `lib/core/portfolioScenario.ts` (بدونِ تغییر)

## بازبینیِ موتور — نقصِ واقعی پیدا نشد

موتورِ Codex با ۱۳ حالتِ مرزی آزموده شد (مثالِ پذیرش، زیانِ کامل، وزنِ ۹۹٫۹۹، سه‌یک‌سوم،
وزنِ صفر با فرضِ خالی، فرضِ مفقود، وزنِ منفی، تورمِ ‎−۱۰۰، بازدهِ زیرِ ‎−۱۰۰، شناسهٔ تکراری،
`NaN`، سرریزِ عددی). همه درست رفتار کردند، پس **چیزی اصلاح نشد** — اختراعِ نقص برای
نشان‌دادنِ کار، خودش یک نقص است.

مثالِ پذیرش، خروجیِ واقعی:

```
{"status":"complete","returnPct":9,"finalValue":1090,"profitLoss":90,
 "realReturnPct":-0.909090909090915,
 "contributions":[{"id":"a","contributionPctPoints":12,...},{"b":-3},{"c":0}]}
```

## اندازه‌گیریِ مرورگر — Chromium، نه چشم

| بررسی | ۱۴۴۰ | ۳۹۰ | ۳۶۰ |
|---|---|---|---|
| اسکرولِ افقی (px) | ۰ | ۰ | ۰ |
| خطای JS | ۰ | ۰ | ۰ |
| `dir` | rtl | rtl | rtl |

رفتارهایی که در همان مرورگر تأیید شدند:

- نمونهٔ فرضی → `۱٬۰۹۰ تومان`، `۹٫۰۰٪`، بازدهٔ واقعی `−۰٫۹۱٪`، و ستونِ «واحد درصد» موجود.
- خالی‌کردنِ یک فرضِ دارایی → «نتیجهٔ کل سبد ساخته نشد» و پوششِ `۴۰٫۰۰٪`. هیچ عددی برای
  کلِ سبد ساخته نشد.
- وزنِ ۵۰/۳۰/۱۰ → پیامِ خطا صریحاً واژهٔ «نرمال» را می‌آورد و جمعِ `۹۰٫۰۰٪` را نشان می‌دهد.
- ۱۴ بار `Tab` → هر ۱۴ عنصر حلقهٔ فوکوسِ دیدنی داشتند.
