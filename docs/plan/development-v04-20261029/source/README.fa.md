# بسته شروع توسعه — نسخه ۰٫۴

این نسخه برای رفع فاصله میان برنامه محصول و مأموریت اجرایی آماده شده است. درخواست تازه آرش برای شروع توسعه، محدودیت عمومی «فقط برنامه‌ریزی» در نسخه قبلی را جایگزین می‌کند. اختیارات هزینه، تولید، پذیرش بصری و توصیه شخصی محفوظ‌اند.

## مسیر خواندن

۱. DEVELOPER-HANDOFF-DRAFT.fa.md — مأموریت شروع برای هماهنگ‌کننده موجود.
۲. EXECUTION-BACKLOG.fa.md — سه تحویل نخست، تسک‌های P00 تا P15، ترتیب و معیار پذیرش.
۳. ARASH-PLATFORM-WORKING-PLAN.fa.md — نیازهای تفصیلی، تمام پاسخ‌های محفوظ و تصمیم‌های باز.
۴. PHASE-ONE-DELIVERY.fa.md — قراردادهای مشترک، پذیرش بین حوزه‌ای و حدود فاز یک.
۵. HANDOFF-REVIEW.fa.md — شاهد تاریخی تطبیق سه مسیر؛ وضعیت زنده نیست.

RESEARCH-DESIGN.fa.md همان فصل پژوهش سند مادر است؛ خواندن دوباره لازم نیست. این نسخه روش اقتصادی تازه، مقدار بودجه یا انتخاب بصری تعیین‌نشده را به جای آرش تصویب نمی‌کند. مجری تصمیم مرتبط را با پیشنهاد آماده می‌کند و کار مستقل ادامه می‌یابد.

## تقدم و محل

مأموریت و دستورکار نسخه۰٫۴ بر عبارت‌های برنامه‌ریزی‌فقط در رسید تاریخی نسخه۰٫۳ مقدم‌اند؛ خود شواهد تاریخی تغییر نکرده‌اند. نسخه قبلی جدا محفوظ است. فایل‌های این بسته در محیط ابری گفتگو هستند؛ هنوز در مخزن، لپ‌تاپ یا چت مجری ثبت/ارسال نشده‌اند. بسته آماده واگذاری است؛ تهیه آن به معنی شروع واقعی اجرا نیست.

وضعیت اجرایی پس از انتقال فقط در COMMAND-CENTER موجود نگهداری شود؛ این README دفتر وضعیت تازه نیست. MANIFEST.json اندازه و SHA256 هفت فایل Markdown را ثبت می‌کند.
