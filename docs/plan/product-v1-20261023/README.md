## مرجع‌ها و تقدم
جهت: [بلوپرینت](../../PRODUCT-BLUEPRINT.md)؛ تصمیم: [دفتر تصمیم](../../DECISION-LOG.md#product-v1-research-to-delivery-20261023)؛ وضعیت زنده: [مرکز فرمان](../../COMMAND-CENTER.md). جدول GAPS فقط snapshot مستندات در زمان تهیه است و داشبورد دوم نیست. وضعیت migration صرفاً در [دفتر نصب](../../MIGRATION-LEDGER.md) ثبت می‌شود.

پژوهش عمومی رقیب جدید متوقف است. محدودیت‌های قابل مشاهده بسته شده محسوب نمی‌شوند. هیچ داده حساب، رمز، نام اعضای رقبا یا تصویر خصوصی در این بسته درج نشده است.

## حدود تحویل
تعریف، ترتیب و معیارها مصوب مالک‌اند. طرح تصویری هنوز پذیرش بصری مالک ندارد. قیمت خدمت، مدت دسترسی تجاری، تأمین‌کننده داده/مدل و نام سه عضو آزمایش مصوب فرض نشده‌اند. این‌ها جلوی آماده‌سازی بسته یا آزمون مصنوعی مستقل را نمی‌گیرند؛ استفاده واقعی وابسته به تصمیم مربوط است.
