## ۴) قیدهای تحویل (روی هر WP)
1. **PR جدا** به برنچِ توسعه (نه merge مستقیم به `main`)؛ عنوان و شرحِ فارسی.
2. `npm run build` + `npm run typecheck` + `npm run test:core` **سبز** — در PR گزارش بده.
3. **متنِ حساس** (کارنامه، روایتِ تحلیلی، دروسِ آموزشی، متنِ حقوقی) → **تأییدِ آرش قبل از انتشار**؛ خودت منتشر نکن.
4. هیچ درجِ مخرب در DB؛ جدول‌های append-only دست‌نخورده.
5. اگر یک WP بلاکرِ داده/تصمیم خورد، **صادقانه اعلام کن** و رد شو — عددِ ساختگی نگذار.
