# نقشهٔ راه محصول — پلتفرم آرش صفری
**نسخه ۱ · تیر ۱۴۰۵ · سند زنده — بعد از هر فاز بازنگری شود**

> قطب‌نما: **کاربر هر روز برگردد.** هر فیچر فقط اگر به این سؤال جواب بدهد وارد می‌شود:
> «این چیز، چه دلیلی برای بازگشتِ فردای کاربر می‌سازد؟»

---

## ۰) وضع موجود (دارایی‌های فعلی — چیزی را دوباره نسازیم)

| دارایی | وضعیت |
|---|---|
| برند (لوگو/پالت/Pelak) + لندینگ زنده (تیکر، پنل بازار، بنتو) | ✅ لایو |
| آزمون ریسک ۲۲ سؤالی + پرتفوی پیشنهادی مشاور + داشبورد | ✅ لایو |
| رصد بازار: کریپتو + انس طلا (جهانی) · طلا/سکه/ارز/تتر تومانی/صندوق‌ها (رله) | ✅ لایو |
| رلهٔ داخل ایران → **پوش به Supabase** (مقاوم به قطعی اینترنت بین‌الملل) | ✅ لایو |
| دیده‌بان صندوق‌ها (KPI، نقشهٔ بازار، فیلتر نوع) | ✅ لایو |
| واچ‌لیست + هشدار قیمت (فقط کریپتو) + DM تلگرام + cron پنج‌دقیقه‌ای | ✅ لایو |
| وبینار (ثبت‌نام/پرداخت زرین‌پال/دعوت کانال) · اطلاعیه‌های هدفمند · پنل ادمین | ✅ لایو |
| سهام بورس (brsapi) | ⏳ نیازمند ست‌کردن `BRSAPI_STOCKS_URL` روی رله |

**شکاف اصلی:** سایت «مقصدِ گاه‌به‌گاه» است، نه «عادتِ روزانه». دادهٔ زنده داریم؛ **حلقهٔ محتوا و شخصی‌سازی** نداریم.

---

## ۱) حلقهٔ عادت — منطق کل نقشه

```
قیمتِ زنده (هست) → «چرا؟» = یادداشتِ روزانهٔ آرش → نوتیفِ تلگرام/ایمیل
      ↑                                                        ↓
 واچ‌لیست و هشدارِ شخصی  ←  «امروزِ شما» در داشبورد  ←  کلیک و بازگشت
```
سه پایهٔ بازگشتِ روزانه: **داده** (هست) + **روایت** (یادداشت روزانه) + **شخصی‌سازی/نوتیف** (نیمه‌کاره).
هر سه باید با هم کار کنند؛ فیچرِ منفرد عادت نمی‌سازد.

## ۳) زیرساخت و کیفیت — مستمر، موازی با همهٔ فازها
- **تست**: حداقل smoke برای cron/هشدار/پرداخت (پرریسک‌ترین مسیرها)؛ CI فعلی سبز بماند
- **خطایابی**: Sentry (یا مشابه) روی سرور و کلاینت
- **امنیت**: بازبینی RLS بعد از هر جدول جدید؛ سکرت‌ها فقط env؛ rate-limit روی فرم‌های عمومی (الگو موجود)
- **کارایی**: بودجهٔ LCP < ۲.۵s موبایل؛ تصاویر og و لوگوها بهینه
- **پشتیبان‌گیری**: export دوره‌ای Supabase (به‌خصوص price_history)

## ۴) قواعد غیرقابل‌مذاکره (در هر فیچر)
1. **هیچ عدد/آمار/بازدهِ ساختگی؛ هیچ وعدهٔ سود.** دادهٔ نبود = حالت خالی صادقانه
2. ذخیره‌سازی append-only/نسخه‌دار؛ upsert مخرب ممنوع
3. فقط توکن‌های برند؛ فارسی/RTL بی‌نقص؛ فرمت‌ها فقط از `lib/format.ts`
4. هر فیچر با حالت خالی/لودینگ/خطا + موبایل ۳۹۰px تحویل می‌شود
5. `npm run build` سبز = شرط merge
