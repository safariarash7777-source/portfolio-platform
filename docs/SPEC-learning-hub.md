# SPEC — ناحیهٔ ۵: یادگیری / سواد مالی

> **ناحیهٔ ۵ Blueprint.** نیاز ۱ (فهمیدن). مخاطب: غیرحرفه‌ای — «اصلاً اینها یعنی چه؟».
> هدف: هر جای سایت که کاربر به اصطلاحی برخورد، **درجا** بفهمدش؛ و مسیرِ یادگیریِ گام‌به‌گام برای تازه‌وارد.
> سبک: ساده، صادق، **بدونِ وعدهٔ سود، بدونِ سیگنال** (الگو: خانه‌سرمایه/انیگما — ولی ساده‌تر و بی‌تبلیغ).
> **طراحی است؛ اجرا پس از تأیید.** آخرین به‌روزرسانی: ۱۴۰۵/۰۴/۲۷.

## ۱) واژه‌نامهٔ درجا (`lib/glossary.ts` — منبعِ واحد)

هر واژه: `{ term, short (یک‌خطی، tooltip), long (پاراگراف، صفحهٔ واژه‌نامه), seeAlso[] }`.

| واژه | جوابِ یک‌خطی (نمونهٔ tooltip) |
|---|---|
| قیمت پایانی | میانگینِ وزنیِ معاملاتِ روز (با حجمِ مبنا) — مبنای سری‌های تاریخی |
| آخرین قیمت | قیمتِ آخرین معاملهٔ روز؛ با پایانی فرق دارد |
| حجمِ مبنا | حداقلِ حجمِ لازم تا پایانی کاملاً جابه‌جا شود؛ علتِ لختیِ نمادهای کم‌حجم |
| دامنهٔ نوسان | سقف/کفِ مجازِ تغییرِ قیمت در روز |
| صفِ خرید/فروش | تجمعِ سفارش در سقف/کفِ دامنه (نامِ رسمیِ وضعیت) |
| حقیقی / حقوقی | خریدار/فروشندهٔ خرد در برابرِ نهادی |
| سرانهٔ خریدِ حقیقی | ارزشِ خریدِ حقیقی ÷ تعدادِ خریدار — نشانهٔ ورودِ پول |
| قدرتِ خریدار | نسبتِ سرانهٔ خرید به فروشِ حقیقی |
| NAV (ابطال/صدور) | ارزشِ خالصِ داراییِ هر واحدِ صندوق |
| حبابِ صندوق | فاصلهٔ قیمت از NAVِ ابطال: `(قیمت−NAV)/NAV` |
| P/E (TTM) | قیمت ÷ سودِ هر سهمِ ۱۲ماهِ اخیر — با میانگینِ تاریخی معنا دارد |
| EPS / DPS | سودِ هر سهم / سودِ تقسیمیِ هر سهم |
| ETF | صندوقِ قابلِ معامله (سهامی، طلا، درآمدِ ثابت، اهرمی…) |
| تعدیلِ قیمت | شکستِ سری بر اثرِ افزایشِ سرمایه/تقسیمِ سود |
| ن-۱۰ / ن-۳۰ | صورتِ سود و زیان / گزارشِ فعالیتِ ماهانه (کدال) |
| کدال | سامانهٔ رسمیِ افشای اطلاعاتِ شرکت‌ها |
| حقِ تقدم (…ح) | حقِ خریدِ سهمِ جدید در افزایشِ سرمایه |
| بازارِ پایه | تابلوی پرریسک‌ترِ فرابورس (زرد/نارنجی/قرمز) |
| توقفِ نماد | تعلیقِ معاملات به دستورِ ناظر (مجمع/افشا/نوسان) |

*(فهرست زنده؛ هر اصطلاحِ جدید در UI اول اینجا اضافه شود — «منبعِ واحدِ حقیقتِ واژگان».)*

## ۲) مسیرِ یادگیریِ گام‌به‌گام (`/learn`)
دروسِ کوتاه، به‌ترتیبِ سواد — از صفر:
1. **بورس چیست و چرا؟** (مقدماتی؛ ریسک و افقِ زمانی).
2. **چطور یک نماد را بخوانم؟** (تابلوخوانیِ ساده: پایانی/آخرین، حقیقی/حقوقی، صف).
3. **تحلیلِ بنیادی به زبانِ ساده** (گزارشِ ماهانه، سود، نرخ در برابرِ حجم).
4. **صندوق‌ها: راهِ ساده‌ترِ سرمایه‌گذاری** (ETF، NAV، حباب، انواع).
5. **ریسک و سبدچینی** (تنوع، تناسب با پروفایلِ ریسک — بدونِ توصیهٔ نماد).
6. **راهنمای قطب‌نمای بازار** (چطور از خودِ محصول استفاده کنم: کارتِ نماد، کارنامه، رصد).

هر درس: متنِ کوتاه + واژه‌های کلیدیِ لینک‌دار به واژه‌نامه + «قدمِ بعدی».

## ۳) نگاشتِ tooltip (کجا کدام واژه)
کامپوننتِ `<Term id="...">` که `short` را به‌صورتِ tooltip نشان می‌دهد و به صفحهٔ واژه لینک می‌دهد:
- شناسنامهٔ نماد / کارتِ بنیادی → P/E, EPS, پایانی/آخرین, حقیقی/حقوقی.
- صندوق‌ها → NAV, حباب, ETF.
- نبضِ بازار → دامنه, صف, حجمِ مبنا.
- پنلِ رصد → سرانهٔ خرید, قدرتِ خریدار.

## ۴) چیدمان و مسیرها
- `/learn` — هابِ یادگیری (کارت‌های دروس + جستجوی واژه‌نامه).
- `/learn/[slug]` — هر درس.
- `/learn/glossary` — واژه‌نامهٔ کامل (از `lib/glossary.ts`).
- `<Term>` — tooltipِ درجا، همه‌جا. وبینارها (`/webinars`) هم ذیلِ همین ناحیه گروه می‌شوند.

## ۵) قیدها
- محتوا آموزشی/مفهومی؛ **هیچ توصیهٔ نماد، سیگنال، یا وعدهٔ بازدهی** (حتی در مثال‌ها). vocab رعایت شود.
- عددهای مثال، صریحاً «نمونهٔ نمایشی».
- RTL/توکن/format-helpers؛ فونتِ سلف‌هاست.
- متنِ آموزشی سواد مالی است، نه مشاورهٔ حقوقی/مالیِ شخص‌محور.

## ۶) گامِ اجرا (پس از تأیید — فاز ۲)
`lib/glossary.ts` (داده + تست) → `<Term>` → `/learn` + `/learn/[slug]` + `/learn/glossary`. محتوای دروس با تأییدِ آرش (متنِ حساس).
